# 素材、设备与校准

[English](data.en.md) | 中文

素材库保存用户导入的科学文件及其可追溯资料。素材身份、固定版本、设备快照与校准关系由数据能力维护，本页写用户要什么以及必须保持的产品规则；具体行为与接口见[素材库子系统](../subsystems/library.md)与[参考](../references.md)。

## 素材与固定版本

- 每个文件在导入时获得稳定素材身份；名称、缩略图或资料更新不改变身份。
- 素材与集合都有固定版本；集合的成员与顺序在受理时固定，向已有集合追加不改变已有成员的顺序。
- 新运行采用纠正后的资料并记录；旧运行不因资料更新而改变。
- 导入可以建立单图、新集合或向指定集合追加；同一集合可跨夜、跨曝光、跨设备，每个成员保留自己的固定校准关系；追加未配置校准的图像不得静默继承前一晚的平场。
- 成功成员及其关系同时发布，失败成员保留身份并单独报告。

## 导入

- 用户在网页直接选择本机文件或文件夹；文件夹只取当前层支持的文件，不需要先配置授权根。
- 登记阶段读取文件头与结构事实并固定成员顺序；原件复制后校验完整性；登记、原件可读、解析与预览分别报告，部分失败不掩盖成功项。
- 主进度按原件字节与成功数量显示；登记完成不代表整批结束，原件就绪后继续后台预览。
- 后台为可自动预览的图像补长边 100 像素缩略图：同一集合共享固定首帧参数，独立图像分别计算；大图按视口按需准备并缓存。
- 预览失败不影响原件入库，也不做图像质量分析。
- 来源在读取前后发生变化时返回来源已变化并保留可用状态，不发布部分副本；用户确认当前来源后重新导入。
- 分类与拍摄资料保留原始观察值，无依据标为未知，不按文件名猜测；人工非空值优先于文件观察，文件观察优先于受理时冻结的预设，数值 0 是有效值；外部 Agent 在导入前把分组、设备、校准与疑问汇总给用户确认，知识或网络资料只能形成待确认建议，用户可保留未知。

## 设备与设备组合

- 设备分为相机、望远镜、滤镜与赤道仪；设备库包含“我的设备”和“设备组合”，不另设独立拍摄预设。
- 组合只作可选的快捷选择，不是导入前置条件；导入可以直接选设备，也可以选组合后明确实际使用的滤镜与附件，平台不从多片滤镜中猜测。
- 组合至多包含一台相机、一台望远镜、一台赤道仪，可以包含多片滤镜且列表完整；在组合内临时填写的成员不自动登记到设备库；每次使用选择一个组合或不使用。
- 望远镜维护光学附件列表，每项只有名称与正数倍率；有效焦距等于原生焦距乘以所选附件倍率，历史快照不随当前附件修改。
- 相机只维护像元尺寸与像素排列，像素排列表达单色或具体阵列；未指定不等于是单色。
- 滤镜记录实际名称、自由文本 Channel 和可选带宽；网页不提供通道选项，未知通道不猜测，也不从标签补造波长或带宽。
- 赤道仪只记录名称、型号、备注与状态，不提供硬件控制；图像显式应用并冻结设备资料，赤道仪不作为校准适配条件。
- 曝光、Gain、Offset 与实测温度属于每张图像；关联设备不覆盖拍摄资料。
- 修改或删除设备与组合不回写历史快照；删除先预检实际关联影响并返回指纹，确认后按同一选择执行，revision 或影响变化即冲突，不自动重试或扩大范围。
- 删除设备会清理当前组合中的对应成员并保留其他成员的身份与顺序，不自动换成另一台设备或另一片滤镜；删除组合不删除独立设备、图像与科学原件。

## 校准

- 校准关系直接作为素材表的列展示，不另设独立校准卡片、重复成员表或搭配筛选；未配置的槽位不能自动写成“不使用”。
- 单图配置独立版本化；集合使用集合默认加成员覆盖，不动态采用单图的最新绑定；继承、尚未配置、明确不使用与固定目标分开表达。
- 所有槽位可选：Light 可选 Dark、Flat、Bias；Flat 可选 Bias、Dark-flat；Dark 与 Dark-flat 可选 Bias；不强制配置全部槽位。
- 绑定目标必须是对应用途的既有 masterframe 固定版本，不能引用原始校准组或 subframe；原始组仍可管理，并可作 Master 的固定来源。
- 保存校准关系不执行校准；绑定不等于已经执行。
- 集合外层自动显示子帧张数与累计曝光，按整个固定成员范围汇总单帧曝光，不受分页与筛选影响；数值 0 与未知分开。
- 校准候选给出冲突与未知依据；人工 Master 来源与平台实际处理事实分开保留。

## 素材库展示

- 素材库提供简约列表与细节模式；固定集合可以切换成员，图片、名称与参数保留。
- 校准列单行显示最终 Master 名称，版本、来源与诊断按需查看。
- 普通浏览按当前页批量读取校准关系，不重复执行科学检查。
- 本机写入立即刷新；MCP 外部修改通过现有轻量刷新同步，不新建事件系统。
