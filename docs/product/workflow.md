# 工作流与处理

[English](workflow.en.md) | 中文

工作流页说明用户在画布上怎么组织处理、怎么运行、怎么查看与保存结果。画布与工作流复用 ComfyUI 原生体系，平台只补充天文素材、软件调用与结果保存；具体契约见[ComfyUI 原生](../subsystems/comfyui.md)与[画布与 Agent](../subsystems/canvas-agent.md)。

## 原生画布与工作流

- 画布、工作流文件、草稿、自动保存、撤销、转换、队列、执行历史、进度与取消由 ComfyUI 原生体系负责。
- 平台不另建工作流库、项目图关联、完整运行库或第二套图编辑器。
- 重要方案用原生另存为保存；平台不额外保存每次编辑的版本、服务器草稿或永久回执库。
- 外来工作流 JSON 按原生机制打开；缺依赖的图可以保留待修复，不自动安装或替换。
- 项目资料与素材、数据集引用归数据，不关联图文件。

## 选材入图

- 画布以 asset_id 或 dataset_id 引用素材和数据集；数据集成员与校准跟随当前保存内容。
- 用户点击素材名称后选择画布落点，或把整行拖入；节点保留图片、成员切换与参数。
- 成员切换只改变显示选择；调用开始时按当前顺序固定实际成员、原件哈希、资料与校准。
- 查看素材不写画布，也不接管 Agent 的编辑。
- 画布上的外部图片引用保留来源与格式信息，来源断开时保留提示。

## Agent 编辑

- 用户在对话中明确要求后，外部 Agent 直接编辑用户指定的当前活动画布；不设置网页内交接、接管会话或控制标记。
- 日常编辑是本地操作；整图 JSON 只用于导入，或用于用户明确要求替换整张图。
- 写入前核对页面、工作流、画布与内容标记；普通任务不需要逐节点确认。
- 用户手动改变参数、节点、连线或布局后，旧请求因内容标记变化被拒绝；Agent 停止并说明，不自动重读后覆盖。
- 平移、缩放与查看不改变内容标记。
- 切换工作流时暂停旧目标的后续写入与提交，不自动跟随新图；已开始的运行继续。
- 关闭网页后不再接受画布写入；其他业务按各自规则继续。
- 授权来自用户明确指令；平台不解析聊天、不维护授权会话，HTTP 认证保留。
- 重连或更换客户端后先读实际状态；目标或内容不符时停止；结果未知先查原操作回执，不自动重发。

## 运行

- 手动运行与节点自动结果预览复用原生转换、校验、队列、进度与取消；未命名草稿按原生机制提交。
- 内容或参数变化后，自动结果在 500 毫秒合并窗口后提交，不额外保存自建工程或单独的计算快照。
- 结果归属由内容匹配签名决定；每次具体调用固定实际科学输入与参数。
- 默认可复现：使用已校验的登记原件，或先完成准备；用户明确选择“仅引用”时采用较弱保证。
- 准备失败不自动降级；指定目标包含必要依赖，不静默缩小请求；科学处理默认不跨运行自动复用。
- 图与提示词记录使用原生执行历史。
- 具体调用记录固定输入与资料、参数、节点定义内容、软件与 Bundle 版本、提示词与节点关联、状态、错误与日志；后续编辑不改变已有调用事实。
- 取消请求不等于已经停止；断连或结果未知先查询，不自动重放。

## 预览

- 每次运行中实际完成的图像节点自动产生轻量预览，按原生工作流、提示词与节点关联。
- 不保存每个进度帧，不建立完整工作流历史库，不强制使用 Preview 节点。
- 后台结果归属其来源运行，不串到其他工作流或抢占视图。
- 旧预览不保证能恢复完整文件或运行环境；从固定结果继续处理时读取真实完整文件。
- 查看器先给概览，再按当前成员与视口取瓦片；视频播放与暂停、原始帧缩放分开。
- Bundle 节点显示完整参数和本节点产物。小图与点击打开的大图使用同一已检查成员、帧和通道，采用直接像素映射。设置中的小图尺寸只影响显示。
- 有可比的直方图时，灰线显示调参前的结果，彩线显示当前结果。指标带有来源、单位、样本与不可用原因，逐帧表可定位已声明的成员和帧。

## 保存结果与导出

- 只有用户选择的完整结果登记为素材，可以命名或使用默认名；不按中间结果与最终结果分类限制。
- 未被选择的完整中间文件不长期保存；原生图操作不删除已保存素材。
- Data 节点从素材库或外部导入、上游科学引用、原生 IMAGE 输入取得内容；保存到素材库与导出到本机都在用户选择完整成员后触发。
- 两者都支持格式与精度选择，默认原样保留；不自动拉伸、裁切、归一化或覆盖原件，也不重跑上游。
- 格式与精度以接口契约和实际组合验证为准；裁剪、重采样与配准更新并验证 WCS 或标记无效。
- 预览不替代原件；RGB 显示白平衡不是测光校准。

## 继续工作

- 项目资料与当前引用归数据，不关联图文件。
- 可以从保存的图、运行与结果继续；换 Agent 时读取背景摘要。
- 结果未知先核对，恢复不改旧运行。
- 本地记忆可查看、修改、停用与删除；用户明确表达优先于 Agent 分析；分析标注来源项目，不改变运行事实；删除包含历史正文；不保存完整聊天、模型状态或凭据。
