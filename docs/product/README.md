# 产品需求

[English](README.en.md) | 中文

AstroPhotoFlow 是本地运行的天文图像工作台：把拍摄得到的 FITS 文件整理成可追溯的素材，在画布上把软件操作连成处理图，真实执行处理后查看、比较并保存结果。用户可以直接操作，也可以让外部通用 Agent 经平台 MCP 操作同一份数据和用户明确授权的画布。

## 目标闭环

第一批交付验证一条完整链路：

1. 选择一份固定的 FITS 文件或一个有序集合。
2. 把素材加入原生 ComfyUI 画布。
3. 用 Siril 1.4.4 的 Auto Stretch 处理。
4. 查看真实输出文件。
5. 用户选择完整结果并保存到素材库。

手动操作与真实 Agent 调用这两个入口都要能走通，不能只有界面演示。

## 必须保持的产品规则

- 素材身份稳定，素材与集合有固定版本；成员与顺序在受理时固定，后续追加不改变已有成员顺序。
- 编辑与运行复用原生 ComfyUI 画布、工作流、队列、历史与撤销，不另建工作流库、运行库或第二套编辑器。
- 处理结果来自实际软件执行；预览、缩略图和自动结果不能当作科学原件或正式结果。
- 安装、切换版本、永久删除、覆盖、外发和付费按具体计划确认，或由用户明确预授权。
- 同一 workspace 只运行本地网页与领域服务两个常驻进程，数据和科学原件默认留在本机。

## 范围边界

- 不内置聊天、推理、模型会话或生成式模型凭据管理；外部 Agent 是通用工具，通过平台提供的接口工作。
- 不承诺多用户、多个 Agent 无序并发修改同一张图、云集群、任意第三方节点或任意软件自动理解。
- Windows 优先；Linux/WSL 后续单独验证。正式发布与版本号另行批准。
