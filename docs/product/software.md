# 软件与节点

[English](software.en.md) | 中文

平台把天文处理软件与画布节点绑定起来，让用户在图上调用固定版本的软件操作。软件安装、就绪判断与调用事实由软件能力维护，节点定义由节点能力维护；具体契约见[软件子系统](../subsystems/software.md)与[节点子系统](../subsystems/nodes.md)。

## 软件包与版本

- 平台维护固定软件及其配套节点；普通软件来自 Git，固定 tag 或 commit。
- Siril 程序、操作、节点绑定与适配器在独立私有 Bundle 中；平台维护 SDK 与发布快照。
- 软件版本与 Bundle 版本分开显示，互不代替。
- 目标完整封装 Siril 1.4.4 可脚本能力；会话与文件控制按实际能力映射，重复别名可以共享实现。
- 非脚本或 GUI 能力保留说明与限制，不声明假的执行节点。

## 安装与更新

- 安装、切换版本与卸载按网页确认的具体计划执行；敏感登录与许可由用户直接输入。
- 维护不因已有运行或预览被拒绝，也不保留在途运行的旧实现版本。
- 实际程序与节点都加载通过才算就绪；checkout 成功不等于可用。
- 软件专用副本与素材分开；卸载保留素材、节点定义与工作流；首次迁移保留原独立程序。
- 更新先列出影响与参数变化；缺失节点在图中保留提示；旧软件不承诺长期并存或复现旧运行。
- Bundle 版本下拉框按官方 Git 标签检查并可刷新；未安装时优先最新正式版，缺兼容正式版时选择兼容开发版，已有安装保留当前版本。
- 灰色项说明系统、SDK、声明格式或必要文件不兼容的原因；选择后复核当前与目标版本、程序版本、tag、commit 与节点变化，再确认安装或切换。
- 确认计划始终指向当时选定的提交；检查失败时保留已安装信息与上次成功列表。

## 热加载

- 前端 Vue、TypeScript 与 CSS 由开发服务自动更新。
- 已安装 Bundle 的 SDK Python 适配器与节点定义变化，以及安装、更新、卸载，无需重启服务即可加载、更新或移除能力。
- 平台后端的业务 Python 不自动重载。
- 热加载必须真实验证，不能从页面刷新推断。

## 节点定义

- 节点定义保存在 workspace 的 JSON 中，可以先保存后测试；最近测试结果从同一运行事实读取。
- 更新确认后，实例参数使用新版本默认值；同方向、同名、同类型的端口保留连线，包括重排。
- 改名、改类型或删除节点会断开连线；输入名与输出名各自唯一。
- 平台先封装已有软件操作；Python 节点与复合节点保留后续。
- workspace 一套节点库供各项目使用；复合内部编辑只影响当前工作流，不回写公共定义。

## 调用归属

- 具体软件调用归软件能力，结果文件事实归数据，跨模块装配归接口。
- 平台不建立 Workflow 或 Run 生命周期。
- 取消受理、实际停止、保存、应用、执行与素材登记分别表达。

## 能力发现

- Skill 与已知工作流直达；需要发现时按工具、节点、软件操作分型混合检索，每次最多 10 个候选，完整定义按需读取。
- 本地固定 embedding 只用于检索；失败时降级为关键词并说明原因。
- 默认不索引聊天、记忆或科学字节；排名不作授权。
- MCP 按数据、节点与画布领域提供少量入口，具体操作按需发现或直接调用。
- 整夜导入先展示整理清单，用户确认后批量提交并聚合观察结果。
- 不注册空能力；模型与索引实现按实际任务选择。
