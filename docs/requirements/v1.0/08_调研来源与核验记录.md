# 08｜调研来源与核验记录

**访问与整理日期：2026-10-22。**  
以下仅列本次实际读取的关键公开资料。来源链接采用普通 Markdown，可脱离聊天界面阅读。

## 核验方法与限制

本次读取了用户指定的十个仓库的项目说明及相关关键源码；有明确 LICENSE 的项目同时读取其许可文件。ComfyUI、Siril、ASTAP、Astropy 和 Agent 接口采用官方文档核对。

“源码核验”表示在相关实现路径中看到了对应机制，不等于所有分支都已验证，更不等于已安装、运行或完成安全审计。README 自述的功能数量、兼容性或性能，不当作本项目的验收结果。

本次没有对用户 WSL 路径进行访问。需求来自当前对话内粘贴的原文和用户明确的后续选择。

GitHub 链接多数指向 `main`／`master`，属于可变引用。本次没有生成各仓库的不可变 commit 锁；因此本文件是调研来源表，不是软件供应链锁文件。进入开发时须重新固定提交、确认许可证、跑集成测试并记录差异。

## 开发启动时必须补齐的证据

| 项目 | 必须记录 |
|---|---|
| 上游版本 | 仓库、commit SHA／release、获取日期、改动补丁与许可证 |
| 宿主兼容 | ComfyUI 与 Frontend 版本，节点 API、画布与撤销／运行入口测试 |
| Agent | 后端版本、可用能力、工具可达性、权限及运行回执 |
| 工具适配 | 安装位置、版本、配置、星库、参考输入输出、取消与失败测试 |
| 科学数据 | 数据集来源、许可、散列、处理参数、结果与指标计算方式 |
| 发行 | 依赖锁、安装脚本、许可清单、数据迁移／恢复证据 |

这些是工程证据任务，不改变已确定的产品方向；未补齐前不应宣称“兼容所有版本”或“可直接生产使用”。
