# 07｜实施路线与验收清单

**原则：尽早用真实素材验证工作台；素材、版本和记忆的底层模型从一开始建立。**

## 1. 开发阶段

| 阶段 | 主要交付 | 阶段出口 |
|---|---|---|
| D0：关键风险原型 | 固定宿主／上游版本；原生图读写、撤销、提交拦截、缓存失效；FITS 文件型节点；数据契约 | 证明 Extension 路线能完成受控图操作与一次可追溯执行；列明不支持节点 |
| D1：最小真实处理闭环 | 项目基础、引用／复制导入、Siril 初始适配、结果登记、预览、运行记录 | 用真实 FITS 序列处理并从输出回查输入和有效参数 |
| D2：人机统一控制 | Agent Panel 集成、领域工具、版本事务、接管、内外部 MCP | 手动与 Agent 交替改同一图，冲突可见，所有托管运行统一入口 |
| D3：跨软件与素材工作台 | ASTAP、受控 MCP 示例、完整素材索引／集合、图像比较 | 两个实际软件交接正确，CLI 和 MCP 两种通道通过验收 |
| D4：版本、记忆与完整 Agent | 版本恢复、记忆管理、多后端、自动迭代和停止条件 | 重启后继续项目，Agent 能运行—评价—调整，项目间隔离 |
| D5：交付与回归 | 环境计划、升级／回退、故障恢复、安全与许可、完整文档 | 所有 P0 用例通过，源码与安装步骤可重复 |

D1 开始就写入版本和来源，不能等到 D4 才补录历史。D4 是完善管理界面和恢复能力，不是把首版数据要求延后。

## 2. D0 必须解决的阻断项

| 编号 | 原型问题 | 不通过时的处理 |
|---|---|---|
| G-01 | 手动修改、Agent 修改、原生撤销和加载是否都能正确同步版本 | 缩小受支持控件／节点范围；不能宣称统一状态已完成 |
| G-02 | 原生运行按钮、快捷键、Agent 和 MCP 是否都经过运行服务 | 未接通的入口禁用托管执行或明确标非托管 |
| G-03 | 两次相同参数是否按策略实际执行；输入变化是否使缓存失效 | 修复节点输入／失效策略，阻止虚假新运行记录 |
| G-04 | 一个文件型节点能否完成外部 job 并返回受控引用 | 验证序列化与文件路径，不退回 8 位 PNG 主链路 |
| G-05 | 画布关闭后受支持节点的编辑图与 API 图是否一致 | 不支持的节点关闭无界面编辑，不猜测转换 |
| G-06 | 所选 Agent 后端是否真的获得领域工具和限制 | 不能约束的后端不启用授权自动执行模式 |
| G-07 | 锁定版本的许可证和依赖是否明确 | 未授权代码不引入，替换或取得授权 |

## 3. 测试素材与测试层级

建立固定素材清单，记录来源、分发许可、文件散列、帧数、滤镜／曝光、图像尺寸、HDU 和已知参考结果。至少包含正常星场、明显缺陷、损坏 FITS、非 ASCII 路径、只读源目录和不同数值类型。

单位／契约测试不启动完整工具；集成测试使用真实 Siril／ASTAP；E2E 使用真实 ComfyUI 前端；模型行为测试分别验证后端。工具安装成功、聊天能回复和测试 mock 通过不能替代真实处理验收。

首个基准可以使用小规模素材，但发布前还要选取能暴露内存、文件数量和日志压力的测试集。基准机器、数据规模、配置和软件版本一并记录。

## 5. 成功与失败如何判定

真实处理标准样例必须使用同一组已固定输入，保存两组有明确差异的参数运行。用户与 Agent 各至少完成一次修改，能查看输出、指标、历史及项目经验，重启后继续。

至少两个独立天文软件完成数据交接。MCP 示例可以验证协议，但不能单独代替“多软件真实链路”的验收。

任何一项出现原件被未授权覆盖、错误工作流被修改、执行未发生却报成功、运行来源丢失或跨项目数据泄漏，均判定 P0 失败。

## 6. 性能目标的测量方式

暂不写未经测试的“秒开”“超大文件流畅”等承诺。D0 建立基准后记录：冷／热启动耗时、索引吞吐、首次预览耗时、编辑提交延迟、事件重连时间、运行日志开销和峰值内存。

建议初始交互验收目标为：本地小图的已提交修改在正常负载下可及时反馈、长任务不冻结 UI；正式数值阈值由 D0 基准文件固定，再作为回归门槛。不能在未测环境下把建议阈值写成产品实测能力。

## 7. 首版发布清单

- 所有 P0 用例有通过证据或明确阻断记录，阻断项未关闭不得标正式首版。
- 宿主、Agent、依赖、工具和数据 Schema 有版本锁；上游链接落实到 commit／发布版本。
- 交付源码、安装／启动／卸载、升级／回退、数据备份和故障排查说明。
- 包含许可清单、版权通知、测试数据分发权限和外部工具安装边界。
- 提供失败诊断导出，默认去除凭据、私人路径和不必要的素材内容。
- 产品首页明确受支持操作系统、工具版本、节点范围和离线能力边界。

**首版完成的含义：核心闭环与全部 P0 数据／协作要求都通过，而不是阶段 D1 演示可运行。**
