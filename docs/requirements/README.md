# 产品要做成什么

AstroPhotoFlow 是一个本地天文图像工作台：管理素材，把软件操作连成图，真实处理、查看比较结果，并保留继续工作的依据。用户可手动操作，也可让外部通用 Agent 经平台 MCP 操作同一份数据和明确授权的画布。

这是目标与约束，不是完成清单。实现状态只看 [当前上下文](../development/current-context.md)，证据按 [验证记录](../development/test-matrix.md) 查询。本文归并旧需求，保留未完成目标；旧需求编号仍可用于定位历史证据，原文见 Git `51046067:docs/requirements/README.md`。

## 当前优先闭环

固定一份 FITS 或一个有序组 → 加入原生画布 → Siril 1.4.4 Auto Stretch → 查看真实输出 → 用户选择完整结果保存到素材库。手动与真实 Agent 入口分别验证。该操作已有窄接入，不能据此宣称完整科学处理或双入口闭环已完成。

当前交付本地网页、Windows 优先，开发版本用 `X.Y.Z-dev.N`。正式发布须另行明确批准。Linux／WSL 后续单独验证。

## 用户实际怎么用

<a id="scenario-import"></a>

- **导入整理**：按钮选择本机文件／一个文件夹，或让 Agent 读取实际构成后分批导入。文件夹只取当前层支持文件；受理后固定范围、顺序、人工资料和设备快照。登记、原件可读、解析和预览分别报告。部分成功不掩盖失败，重试不重复已完成阶段。夜间目标汇总保留来源和疑义，只选今晚就不自动加历史帧。

<a id="scenario-canvas"></a>

- **选材入图**：按固定素材／组版本及有序成员选择，原生点击放置或整行拖入。保留节点图片、成员切换和参数；查看不写入图或接管 Agent。素材简约列表只显示预览和名称，窄侧栏名称省略且可看全文；细节模式保留资料。

<a id="scenario-processing"></a>

- **真实处理**：支持目标包括深空原始素材、行星原始视频及叠加后期。具体格式与软件组合逐项验证；首帧预览不代表整段视频可执行，199条 Siril 命令资料不代表199个可执行操作。

<a id="scenario-nodes"></a>

- **制作节点**：先封装已有软件操作；Python 函数与复合节点保留后续目标。workspace 一套节点库，各项目可用；测试可选。保存、引擎加载、画布显示与真实运行各自确认。

<a id="scenario-continuity"></a>

- **继续工作**：重要方案用原生另存；从保存图、实际运行和结果继续。换 Agent 按需读取项目背景和摘要；未知结果先核对，恢复方案不改旧运行，也不自动撤销文件写入。

### 数据与设备（原FR-04／14）

- 保留稳定素材身份、现有固定资产／集合版本、元数据、设备组合及校准。集合成员及顺序不随追加自动变化；新运行采用纠正资料并记录，旧运行不改。
- 图像分组由外部Agent根据用户确认决定，MCP只观察文件事实并导入明确名单。支持独立单图、新组及向指定组追加；同目标组可跨夜、跨曝光和设备，各成员采用自己的固定校准关系。追加未配置的校准不能静默继承前夜平场，成功成员及其关系同时发布，失败项保留身份并单独报告。
- 大量子帧采用轻量导入：逐文件读取头与结构事实，来源不变时复用扫描结果；保留原件复制及完整性校验。导入后在后台为全部可自动预览图片补齐长边100px缩略图，组内严格共享固定首帧参数，独立图分别计算；实际视口优先，逐张替换占位，不显示缩略图进度条。大图按需准备并缓存。导入完成不等待全组预览，预览失败不否定原件入库，不执行质量分析。
- 外部Agent在导入前汇总分组、设备、校准与相关疑问并向用户确认。知识或网络资料可形成待确认建议，用户可保留未知；不从设备能力补造实际拍摄参数。未知放行仅适用于已说明并确认的本次未知项，不能绕过已知冲突，不增加后端聊天、强制三阶段确认或待整理区。
- 校准直接作为现有素材表的列展示，取消独立校准卡片、重复成员表及搭配筛选。单元格单行显示最终Master名称，版本、来源及诊断按需查看；所有槽可选，未配置不能自动写成不使用。独立配置与组内配置分别展示，普通浏览批量读取当前页关系，不重复执行科学检查。
- 组外层自动显示子帧张数与累计曝光，后端对整个固定成员范围汇总单帧曝光，不受当前分页／筛选影响，不累加Master或成员累计积分，0与未知分开。当前资料纠正、追加及移除自动反映；明确历史版本采用冻结事实。本机写入后立即刷新，MCP外部修改通过现有轻量刷新同步，不建立新的事件系统。
- 图片目标名称和拍摄时间可查询；Master另记录制作时间与固定来源的拍摄范围，不把入库时间当拍摄时间，不增加设备或光路有效时间。单图校准配置独立版本化，组使用组默认与成员覆盖，不动态采用单图最新绑定；继承、尚未配置、明确不使用和固定目标分开表达。校准候选提供冲突／未知依据，保存关系不执行校准；绑定目标只能是对应用途的既有masterframe固定版本，不能引用原始校准组或subframe；原始组仍可管理及作为Master固定来源。Light可选Dark／Flat／Bias，Flat可选Bias／Dark-flat，Dark／Dark-flat可选Bias，不强制全部配置。人工Master来源与平台实际处理事实分开保留。
- 科学原件默认只读；引用／托管有明确区别。网页直接选择本机来源，无需预设授权根；原有根目录、上传、CLI及MCP接口保留。来源变化经确认后沿同素材新增内容记录，仅显式更新所选引用，不改旧组或承诺找回已覆盖字节。
- 省略、null、0不同；人工值、观察值及未知保留语义。设备修改或删除不回写历史快照；校准固定目标版本，支持默认、继承、不使用和成员覆盖，不把绑定当作已执行校准。
- 设备／组合确认影响后直接删除；素材继续回收站与原件保护。组合中相机和望远镜分别允许零或一台（注册与组合内设备合计），滤镜可多片且列表完整展示。取消独立拍摄预设。导入可直接选择设备，组合仅作可选快捷选择；曝光、Gain／Offset和实测温度属于每张图像。关联设备不能覆盖拍摄资料，批量补缺失与纠正已有值分开表达，0保留。相机像元尺寸一个字段、不要求原生位深；设备不维护序列号，望远镜不维护口径，相机不再单独维护传感器类型，以“像素排列”（cfa_pattern）表达单色或具体阵列，未指定不等于单色；滤镜维护实际名称、自由文本Channel及可选带宽；网页不提供通道选项，外部Agent可依据明确用途或可靠资料填写Channel，未知不猜，不从标签补造波长或带宽。组合标签显示Channel＋带宽，未知通道明确标示并保留原名辨认；选择器保留实际名称，同通道的不同滤镜身份不合并。设备支持相机、望远镜、滤镜和赤道仪；赤道仪仅维护名称、型号、备注和状态，不提供硬件控制。组合至多一台赤道仪，图像显式应用并冻结资料；赤道仪不作为校准适配条件。望远镜内部维护光学附件列表，每项仅名称及正数倍率。组合一次选一个或不使用；有效焦距由原生焦距乘所选倍率派生，历史快照不随当前附件修改。
- 表单复用原生组件。设备以组合为主入口，项目页从此处移出；批量管理显式进入，完成或搜索／分页／切页签退出。具体当前行为见 [设备规则](../development/settings-organization.md) 和 [删除规则](../development/settings-management.md)。
- 移除素材前展示可核对的引用影响，确认后原生图中的缺失引用保留提示；不为扫描全部工作流建立项目图关联库。永久清理不绕过现有活动任务、原件及校准保护。

### 运行、预览及保存结果（原FR-05／09／10／11）

- 手动运行与节点自动结果预览均复用原生转换、校验、队列、进度和取消，未命名草稿按ComfyUI机制提交。自动结果在连接或修改参数后500毫秒合并提交；不要求额外保存自研工程，不另存完整图计算快照。内容匹配签名用于结果归属，实际科学输入与参数在具体调用中固定。
- 默认可复现：使用已验证固定内容或先准备，不重复复制已有固定托管输入；用户可明确选“仅引用”并记录较弱保证。准备失败不自动降级。指定目标包含必要依赖，不静默缩小请求范围；科学处理默认不跨运行自动复用。
- 图与prompt记录使用原生执行历史。具体软件调用记录采用的固定输入及资料、参数、节点定义内容、软件／Bundle版本、原生prompt／节点关联、状态、错误和日志；data保存经过检查的结果与文件事实。后续编辑不改既有调用事实；Bundle不提供在途实现保护。再次处理通过原生队列产生新prompt，不建立平台Workflow／Run生命周期。
- 取消请求不等于实际停止；断连或未知先查询，不自动重放。素材保存失败先核对已有文件及登记，不重跑处理或重复入库。request ID／prompt_id本身不保证防重。
- 每个本次实际完成的图像节点自动产生轻量预览，按原生workflow／prompt／节点／输出关联必要结果；不保存进度每帧、不建设完整工作流历史库、不强迫Preview节点、不把全部节点设终点或扩大执行范围。A后台结果归A，不串B或抢视图。
- 只有用户选择的完整结果才登记素材，可命名或用默认名，不按中间／最终分类限制。未选完整中间文件不长期保存；原生图操作不删除已保存素材。旧预览不保证完整文件或环境仍可恢复；固定结果继续处理必须读取真实完整文件，不依赖缩略图或旧内存缓存。
- Data节点可从素材库／外部导入、上游科学引用或原生IMAGE接入数据，预览并传递science；保存到素材库与导出本机均由用户选择完整成员后触发。两者支持格式与精度选择，默认原样保留，不自动拉伸、裁切、归一化、覆盖原件或重跑上游。具体格式精度以接口契约与实际组合验证为准。
- 科学格式、精度、HDU／切片及单位明确交接；不支持的组合明确报错。裁切、重采样及配准后的WCS更新、验证或标无效。预览不替代原件，RGB显示白平衡不当作测光校准。
- 查看器概览先行、按当前成员／视口取瓦片，不给整组预建金字塔；视频播放和暂停原件帧放大分开。节点自动结果预览使用完整科学输入，处理与分析操作按Bundle显式策略默认启用，导出、脚本和查询管理操作保持手动；运行期间修改合并为最新一次，失败不循环重跑，切图暂停后续提交。已有快速样本预览默认收起，约350毫秒防抖，仅适用于已声明支持的操作；真实结果与快速样本均可选512／1024／2048px或原尺寸。
- 比较标明配准、尺寸、ROI、相同／独立拉伸；指标标算法、单位、样本和不可用原因，不把缺失当0，不用单一背景指标或模型意见替代科学判断。当前显示细节见 [预览规则](../development/library-preview.md)。

### 软件和节点（原FR-03／13／16）

- 平台维护固定软件与配套节点。Siril程序、操作、节点绑定及适配器在独立私有Bundle；平台维护SDK与发布快照。普通Git、固定tag/commit，软件版本与Bundle版本分开。本轮目标为完整封装Siril 1.4.4可脚本能力；会话／文件控制按实际能力映射，重复别名可共享实现。非脚本／GUI能力保留完整说明和限制，支持的查看交互复用通用查看器，其余待另定GUI方案，不声明假执行节点。
- 安装、更新及卸载按网页确认的具体计划进行，敏感登录／许可由用户直接输入；不因已有运行或预览拒绝 Bundle 维护，不保留在途旧实现版本。实际程序和节点加载通过才就绪，checkout成功不等于可用。
- 专用软件副本与素材分开；卸载保留素材、节点定义及工作流，首次迁移保留原独立程序。更新先列影响和参数变化，缺失节点留图提示；旧软件不承诺长期并存或必能复现旧运行。
- 自定义定义保存workspace JSON，可先保存后测试；最近测试从同一运行事实读取，修改后说明是旧内容。更新确认后实例参数全用新版默认；同方向、同名、同类型端口保线（含重排），改名／改类型／删除断线。输入名及输出名各自唯一，不扩展为任意第三方节点限制。
- 前端 Vue／TypeScript／CSS 修改通过开发服务自动更新；已安装 Bundle 的 SDK Python 适配器与节点定义变化，以及 Bundle 安装／更新／卸载，无需重启服务即可加载、更新或移除能力。平台后端业务 Python 不在自动重载范围。热加载须真实验证，不以刷新推定支持。

### 能力发现与本地记忆（原FR-07／12）

- Skill／已知workflow能力直达，需要发现才按工具、节点、软件操作分型混合检索；每次最多10候选，完整定义按需读。本地固定embedding只作检索，失败明确降为关键词并说明原因；不默认索引聊天、记忆或科学字节，不以排名作为授权。
- MCP按数据管理、节点与画布领域提供少量入口，具体操作按需发现或直接调用；迁移既有能力及Skill／参考／协议验证，不留旧扁平入口。整夜导入先检查并展示整理清单，用户确认后批量提交并聚合观察。Skill管理和反馈领域按实际需求另行实现，不注册空能力。模型及索引实现到实际任务再选，Judge仅为后续外部评价边界。
- 本地保存项目背景、工作流经验、偏好及主动交接摘要，按需读取。用户明确表达优先于Agent分析，项目约定优先于跨项目偏好；分析标来源项目，不改运行事实。用户满意后外部Agent可总结并保存偏好。
- 记忆可查看、修改、停用和删除；只有个人偏好要求查看旧正文并恢复为当前，恢复不改旧运行，删除包括历史正文。停用／删除后不再检索；不扩展通用修订框架，不保存完整聊天、模型私有状态或会话凭据。

### 工作台、安全与交付（原FR-13～15／NFR-01～08）

- 两个常驻服务，默认workspace由config.toml选择，不建身份登记或搬迁服务。保留最新配置、实际运行信息、最近启停结果；性能设置下次显式重启采用，繁忙或不能确认空闲时拒绝，不排队自动重启。
- 健康的同workspace服务复用，端口占用自动选择，双服务就绪后安全回写实际端口及允许来源，并返回网页地址。控制和配置保存均不漂移运行目标；控制未知先核对，升级前备份数据库并保护原件和令牌。
- 画布常驻，保留节点库→素材库→工作流及软件包入口，侧栏可收起调宽；设备在导入旁。设置从底部入口打开，工作台置顶默认打开；本地Nodes 2.0固定启用，隐藏无关原生功能、内部迁移及模型云设置，上游通知关闭。已保存图默认延迟自动保存，用户明确关闭值保留。
- 普通操作连续；安装、永久删除、覆盖、外发、付费按具体计划确认或明确预授权。实际提交验证认证、目标和范围；文本、Skill及自报身份不扩大权限，虚拟环境不当恶意代码沙箱。
- 程序与workspace数据分离，升级／卸载不自动删用户数据。只发送任务必要资料／预览，科学原件不默认外发；日志、图、导出及诊断脱敏。不内置Agent、聊天、推理或生成式模型凭据管理。
- 大文件按需、异步处理，不把全量科学文件读入浏览器或模型上下文；长任务保持可交互，未知进度显示阶段／时长／日志。性能结论记录机器、版本、数据规模及实测，不编造数值门槛。
- 支持范围按节点／格式／软件／平台的实际组合记录；可追溯不等于位级可复现。目标为锁定组合可重建、仓库外wheel安装与无Node的sdist重建；未验证平台不写通过。
