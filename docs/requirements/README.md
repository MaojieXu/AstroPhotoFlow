# 产品要做成什么

AstroPhotoFlow 是一个本地天文图像工作台：管理素材，把软件操作连成图，真实处理、查看比较结果，并保留继续工作的依据。用户可手动操作，也可让外部通用 Agent 经平台 MCP 操作同一份数据和明确授权的画布。

这是目标与约束，不是完成清单。实现状态只看 [当前上下文](../development/current-context.md)，证据按 [验证记录](../development/test-matrix.md) 查询。本文归并旧需求，保留未完成目标；旧需求编号仍可用于定位历史证据，原文见 Git `51046067:docs/requirements/README.md`。

## 当前优先闭环

固定一份 FITS 或一个有序组 → 加入原生画布 → Siril 1.4.4 Auto Stretch → 查看真实输出 → 用户选择完整结果保存到素材库。手动与真实 Agent 入口分别验证。该操作已有窄接入，不能据此宣称完整项目、运行持久化或双入口闭环已完成。

当前交付本地网页、Windows 优先，开发版本用 `X.Y.Z-dev.N`。正式发布须另行明确批准。Linux／WSL 后续单独验证。

## 用户实际怎么用

<a id="scenario-import"></a>

- **导入整理**：按钮选择本机文件／一个文件夹，或让 Agent 读取实际构成后分批导入。文件夹只取当前层支持文件；受理后固定范围、顺序、人工资料和设备快照。登记、原件可读、解析和预览分别报告。部分成功不掩盖失败，重试不重复已完成阶段。夜间目标汇总保留来源和疑义，只选今晚就不自动加历史帧。

<a id="scenario-canvas"></a>

- **选材入图**：按固定素材／组版本及有序成员选择，原生点击放置或整行拖入。保留节点图片、成员切换和参数；查看不写入图或接管 Agent。素材简约列表只显示预览和名称，窄侧栏名称省略且可看全文；细节模式保留资料。

<a id="scenario-processing"></a>

- **真实处理**：支持目标包括深空原始素材、行星原始视频及叠加后期。具体格式与软件组合逐项验证；首帧预览不代表整段视频可执行，199条 Siril 命令资料不代表199个可执行操作。

<a id="scenario-nodes"></a>

- **制作节点**：先封装已有软件操作；Python 函数与复合节点保留后续目标。workspace 一套节点库，各项目可用；测试可选。保存、引擎加载、画布显示与真实运行各自确认。

<a id="scenario-continuity"></a>

- **继续工作**：重要方案用原生另存；从保存图、实际运行和结果继续。换 Agent 按需读取项目背景和摘要；未知结果先核对，恢复方案不改旧运行，也不自动撤销文件写入。

## 必须保持的规则

<a id="fr-04-数据素材与业务资料"></a>
<a id="5-数据与科学处理规则"></a>
<a id="library-minimal-toolbar"></a>

### 数据与设备（原FR-04／14）

- 保留稳定素材身份、现有固定资产／集合版本、元数据、设备组合、拍摄预设及校准。集合成员及顺序不随追加自动变化；新运行采用纠正资料并记录，旧运行不改。
- 科学原件默认只读；引用／托管有明确区别。网页直接选择本机来源，无需预设授权根；原有根目录、上传、CLI及MCP接口保留。来源变化经确认后沿同素材新增内容记录，仅显式更新所选引用，不改旧组或承诺找回已覆盖字节。
- 省略、null、0不同；人工值、观察值、预设及未知保留语义。设备修改或删除不回写历史快照；校准固定目标版本，支持默认、继承、不使用和成员覆盖，不把绑定当作已执行校准。
- 设备／组合／预设确认影响后直接删除；素材继续回收站与原件保护。组合可多滤镜，拍摄预设选一片或用默认；Gain／Offset及名称中的0不省略。相机像元尺寸一个字段、不要求原生位深；滤镜为名称及可选带宽，附件倍率沿现有字段。
- 表单复用原生组件。设备以组合为主入口，项目页从此处移出；批量管理显式进入，完成或搜索／分页／切页签退出。具体当前行为见 [设备规则](../development/settings-organization.md) 和 [删除规则](../development/settings-management.md)。
- 移除素材前应展示工作流影响，确认后图中保留缺失提示；永久清理不绕过现有活动任务、原件及校准保护。

### 当前图与 Agent 编辑（原FR-01／02／07／08）

- 一个项目可有多条图；项目资料归数据模块，当前图只用原生 workspace JSON，补关联及保存／改名／另存／删除联动。外来JSON需明确关联，缺依赖图可保留待修复，不自动安装或替换。
- 自动保存、会话撤销和浏览器草稿复用原生。重要方案另存；不建永久逐编辑修订、服务端草稿、第二套图编辑器或永久回执库。断连草稿不冒充已保存，重连分歧不自动覆盖。
- 用户在对话中明确要求修改后，Agent 直接通过内部 MCP／CLI 编辑明确的活动画布，不设网页交接、控制标记或接管／交回会话。日常局部改图，整图JSON用于导入或明确替换。实际写入核对页面、工作流、画布和内容标记；普通任务不逐节点确认。
- 手改参数、节点、连线、布局或撤销改变内容标记，旧请求拒绝后 Agent 停止并说明，不自动重读后覆盖。查看、平移和缩放不改变内容标记。切图暂停旧目标后续写入和新提交，不自动跟随新图；已有运行继续。关闭网页后不接受画布写入，非画布业务按所属规则提供。
- 授权依据由 Agent 按用户明确指令遵守，软件不解析聊天、不维护授权会话；平台 HTTP 认证保留。重连或换客户端后读取实际状态；目标或内容不一致就停止，未知结果先查询原操作回执，不自动重发。

<a id="fr-09-原生引擎执行与运行记录"></a>

### 运行、预览及保存结果（原FR-05／09／10／11）

- 运行前立即成功保存当前画布；失败不提交。原生准备／转换各一次，核对采用内容一致；按钮、快捷键、自动队列及MCP托管入口遵循同一规则。复用原生转换、校验、队列、进度和取消。
- 默认可复现：使用已验证固定内容或先准备，不重复复制已有固定托管输入；用户可明确选“仅引用”并记录较弱保证。准备失败不自动降级。指定目标包含必要依赖，不静默缩小请求范围；科学处理默认不跨运行自动复用。
- 每次运行保留当次编辑图／执行图、实际输入及资料、参数、节点实现、软件版本、原生任务关联、状态、错误和日志。后续图编辑不改已提交的图与输入或历史事实；Bundle 不提供在途实现版本保护。完整重跑和显式续跑创建新运行。
- 取消请求不等于实际停止；断连或未知先查询，不自动重放。素材保存失败先核对已有文件及登记，不重跑处理或重复入库。request ID／prompt_id本身不保证防重。
- 每个本次实际完成的图像节点自动产生轻量预览，按工作流／运行／节点／输出关联并保留多次结果；不保存进度每帧、不强迫Preview节点、不把全部节点设终点或扩大执行范围。A后台结果归A，不串B或抢视图。
- 只有用户选择的完整结果才登记素材，可命名或用默认名，不按中间／最终分类限制。未选完整中间文件不长期保存；删除图只清专属预览，不删已保存素材。旧预览不保证完整文件或环境仍可恢复，续跑不依赖缩略图或旧内存缓存。
- 科学格式、精度、HDU／切片及单位明确交接；不支持的组合明确报错。裁切、重采样及配准后的WCS更新、验证或标无效。预览不替代原件，RGB显示白平衡不当作测光校准。
- 查看器概览先行、按当前成员／视口取瓦片，不给整组预建金字塔；视频播放和暂停原件帧放大分开。Auto Stretch 实时预览用当前固定成员1024px线性样本、约350ms防抖、同版本参数；显示直接采用输出值，正式运行仍用完整原件，不承诺任意上游链式实时预览。
- 比较标明配准、尺寸、ROI、相同／独立拉伸；指标标算法、单位、样本和不可用原因，不把缺失当0，不用单一背景指标或模型意见替代科学判断。当前显示细节见 [预览规则](../development/library-preview.md)。

### 软件和节点（原FR-03／13／16）

- 平台维护固定软件与配套节点。Siril程序、操作、节点绑定及适配器在独立私有Bundle；平台维护SDK与发布快照。普通Git、固定tag/commit，软件版本与Bundle版本分开；首个可执行操作仅Auto Stretch。
- 安装、更新及卸载按网页确认的具体计划进行，敏感登录／许可由用户直接输入；不因已有运行或预览拒绝 Bundle 维护，不保留在途旧实现版本。实际程序和节点加载通过才就绪，checkout成功不等于可用。
- 专用软件副本与素材分开；卸载保留素材、节点定义及工作流，首次迁移保留原独立程序。更新先列影响和参数变化，缺失节点留图提示；旧软件不承诺长期并存或必能复现旧运行。
- 自定义定义保存workspace JSON，可先保存后测试；最近测试从同一运行事实读取，修改后说明是旧内容。更新确认后实例参数全用新版默认；同方向、同名、同类型端口保线（含重排），改名／改类型／删除断线。输入名及输出名各自唯一，不扩展为任意第三方节点限制。
- 前端 Vue／TypeScript／CSS 修改通过开发服务自动更新；已安装 Bundle 的 SDK Python 适配器与节点定义变化，以及 Bundle 安装／更新／卸载，无需重启服务即可加载、更新或移除能力。平台后端业务 Python 不在自动重载范围。热加载须真实验证，不以刷新推定支持。
- 复合内部编辑只影响当前工作流，不回写公共定义；Python／复合仍属后续S6，导出安装的格式和渠道另行决定。

### 能力发现与本地记忆（原FR-07／12）

- Skill／已知workflow能力直达，需要发现才按工具、节点、软件操作分型混合检索；每次最多10候选，完整定义按需读。本地固定embedding只作检索，失败明确降为关键词并说明原因；不默认索引聊天、记忆或科学字节，不以排名作为授权。
- 未来精简MCP整体迁移既有数据工具及Skill／参考／协议验证，不留旧入口；当前保留既有工具，此次Bundle增量不提前实施全量迁移。模型及索引实现到实际任务再选，Judge仅为后续外部评价边界。
- 本地保存项目背景、工作流经验、偏好及主动交接摘要，按需读取。用户明确表达优先于Agent分析，项目约定优先于跨项目偏好；分析标来源项目，不改运行事实。用户满意后外部Agent可总结并保存偏好。
- 记忆可查看、修改、停用和删除；只有个人偏好要求查看旧正文并恢复为当前，恢复不改旧运行，删除包括历史正文。停用／删除后不再检索；不扩展通用修订框架，不保存完整聊天、模型私有状态或会话凭据。

### 工作台、安全与交付（原FR-13～15／NFR-01～08）

- 两个常驻服务，默认workspace由config.toml选择，不建身份登记或搬迁服务。保留最新配置、实际运行信息、最近启停结果；性能设置下次显式重启采用，繁忙或不能确认空闲时拒绝，不排队自动重启。
- 健康的同workspace服务复用，端口占用自动选择，双服务就绪后安全回写实际端口及允许来源，并返回网页地址。控制和配置保存均不漂移运行目标；控制未知先核对，升级前备份数据库并保护原件和令牌。
- 画布常驻，保留节点库→素材库→工作流及软件包入口，侧栏可收起调宽；设备在导入旁。设置从底部入口打开，工作台置顶默认打开；本地Nodes 2.0固定启用，隐藏无关原生功能、内部迁移及模型云设置，上游通知关闭。已保存图默认延迟自动保存，用户明确关闭值保留。
- 普通操作连续；安装、永久删除、覆盖、外发、付费按具体计划确认或明确预授权。实际提交验证认证、目标和范围；文本、Skill及自报身份不扩大权限，虚拟环境不当恶意代码沙箱。
- 程序与workspace数据分离，升级／卸载不自动删用户数据。只发送任务必要资料／预览，科学原件不默认外发；日志、图、导出及诊断脱敏。不内置Agent、聊天、推理或生成式模型凭据管理。
- 大文件按需、异步处理，不把全量科学文件读入浏览器或模型上下文；长任务保持可交互，未知进度显示阶段／时长／日志。性能结论记录机器、版本、数据规模及实测，不编造数值门槛。
- 支持范围按节点／格式／软件／平台的实际组合记录；可追溯不等于位级可复现。目标为锁定组合可重建、仓库外wheel安装与无Node的sdist重建；未验证平台不写通过。

## 保留但不提前展开的目标

完整项目连续性、跨软件交接、完整比较、本地记忆、固定结果显式续跑、Python／复合节点及Windows交付继续保留。器材型号搜索与未知型号手填待排期：不新增设备字段，手填优先，目录值不显示来源标记；既有本地JSON资料路径见 [当前上下文](../development/current-context.md#equipment-model-search-enhancement)，本轮不继续设计。

Linux／WSL、节点导出安装及Judge实际接入另行安排。不承诺多用户、多个Agent无序并发改同图、云集群、任意第三方节点或任意软件自动理解。S0～S6保留原交付阶段含义：基础→数据／软件→编排→真实运行→双入口→完整产品；下一项任务按 [当前计划](../development/implementation-plan.md) 确定，不再照旧Batch预定全部文件和协议。上述未完成产品目标没有取消。
