# 当前素材与存储行为

前端、CLI 和 MCP 支持单图及批量上传，源文件保持原位；上传暂存文件散列后原子归位，不再次整文件复制。配置根目录导入支持 reference／managed，后者在后台复制原件。

```text
workspace/
  config.toml
  data/
    astrophotoflow.sqlite3
    objects/<version-id>/source.<extension>
    previews/
    upload-staging/
    service.token
  input/
  output/
  logs/
  context/
  comfyui-user/
  comfyui-data/
  run/
```

`data` 相对 `config.toml` 解析；`input` 是 ComfyUI 输入目录，不是素材库原图目录。前端组通过数据库关系管理，不镜像成物理文件夹。

资产有稳定身份、版本和 revision；数据集成员及项目引用可以固定到版本。参数修改区分未提供、显式 null 和零值，过期 revision 拒绝覆盖。资料编辑、批量操作、筛选、排序和组内浏览维持已接受实现。

登记、托管、元数据和预览状态分开；登记即可展示，但 availability=unknown 不代表原件就绪。后台内容和预览分别使用服务级有界线程池。文件明确 Header 可逐项分类，人工显式分类覆盖本批次对应字段，未提供字段继续读取文件／预设；未知不按文件名猜测。参数采用人工、文件观察、已冻结预设、未知的优先级。

项目收集跨夜／滤镜的固定资产与组版本。使用组合引用注册设备或保存内联设备；内联不注册，组合不修改设备库。拍摄预设属于组合，接受导入时在同一事务冻结组合、预设、显式设备及预设设备的完整快照；任务重试和恢复沿用原快照。校准库与 Light 视图独立；Master Light 属于亮场。校准默认及成员覆盖随数据集版本保存，缺失键继承、null 不使用，指向固定校准组或 Master 版本；不执行校准或自动匹配。

素材参数引用的设备信息另存为名称、型号、序列号、规格和备注快照。永久删除设备会解除素材版本的设备外键，但素材参数与版本快照仍能显示设备信息；修改设备库资料不会回写到素材快照。素材列表和组成员使用各自的当前快照，项目固定版本使用版本快照；不以设备库当前名称替换历史名称。按设备排序使用每条素材的快照名称；同 ID 的多个历史名称在筛选项合并显示。设备已删除时，已接受任务继续登记，版本外键为空但历史 ID 和快照保留。

回收站提供移除、恢复、永久清理预览和确认清理。真实清理进度意味着不可逆变化；组状态只依据当前待处理成员的真实记录，不因已恢复成员的历史待清理路径缺失误判损坏。损坏照片不能假报恢复，外部 reference 原图及其他资产仍使用的共享路径受到保护。

校准引用和正在生成的大图均参与清理检查。仍被保留组版本引用的校准目标不能清理；选择消费者和目标可先清理消费者、把目标保留为独立可重试记录。不得通过清空旧版本绑定绕过保护。

列表使用最长边100 px的JPEG缩略图；点击按需生成最大边1080 px的大图JPEG并缓存，不放大小图。大图使用同条件子组已保存的固定拉伸基准，与导入共用预览并发限制。已保存的拉伸数值独立使用，参考版本 ID 仅记录来源；删除参考照片不阻止其他成员首次生成或重新生成大图。科学原件只读；后台生成中的缓存持有明确所有权，不能与永久清理互相穿越。

打开大图即自动分析当前照片并生成拉伸预览，不显示底部说明或额外操作按钮，不改变导入时的组基准策略。FITS/XISF保留原件数值精度并采样至最长边1080 px后计算，其他格式从原件解码的像素计算，绝不从已拉伸JPEG反推。RGB先按背景中位数估计各通道白平衡系数，再应用统一的MTF曲线；Mono只拉伸。背景以中位数/MAD估计，阴影截断取-2.8 sigma，目标背景0.25，算法形式参考[Siril官方说明](https://siril.readthedocs.io/en/stable/processing/stretching.html)。白平衡属于预览的背景估计，不是测光色彩校准。

计算出的 `auto_stretch`（算法版本、输入偏移、通道系数、阴影/高光范围和中间调）写入该版本选中HDU的预览配方JSON，不覆盖导入批次的共享基准。后台同时生成大图和100 px缩略图，以同一事务发布两个缓存路径。原件、科学参数、版本身份和其他组成员不变，不增加数据库列；再次打开复用已有结果，缓存重建直接使用保存数值；同一版本正在生成时复用任务。项目引用使用其固定版本配方。生成中的所有权继续阻止并发永久清理，失败不改写原缩略图和配方。

| 格式 | 当前解析／预览范围 |
|---|---|
| FITS | HDU/Header 元数据；支持的 Mono、Bayer、明确 RGB 图像缩略图 |
| 常规图像／HEIF | 静态图像缩略图，具体编码由既有解码器支持 |
| 相机 RAW | rawpy 内嵌预览或既有半尺寸解码 |
| XISF | 第一幅支持的 Gray/RGB 图像及明确 FITSKeywords 分类／参数 |
| SER／已录制视频 | 首帧静态封面，视频解码依赖现有 FFmpeg |
| NumPy | 内容登记与散列，不提供数组查看／预览 |

扩展名和实际解码规则以 modules/data 实现、[对应测试](../development/test-matrix.md)为准；历史双尺寸预览记录保留在归档，不作为当前规格。

FITS RGB 识别兼容显式 CTYPE 通道标记、既有 RA/DEC 三平面布局，以及 `PROGRAM=PixInsight …` 且未声明 CTYPE3 的三平面导出。明确声明其他第三轴的文件、其他来源的无标记三维数据保持不支持，不仅按维度长度猜测 RGB。已识别为 RGB 时不因残留 BAYERPAT 再做去拜耳。
