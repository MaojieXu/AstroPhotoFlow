## 3. 八类共同规则

| 共同问题 | 采用的最小规则 |
|---|---|
| 身份与版本 | 保留已有资产／集合版本和资料revision。工作流复用原生图编号，当前内容校验只防覆盖，不建立永久逐编辑修订。运行使用原生任务关联，不把编号当版权或防重证明 |
| 固定引用与快照 | 项目／工作流保持选定素材和素材组范围；新运行读取修正资料并记录实际值。运行保存当次图、输入、参数和实现，当前JSON文件仍只有一份 |
| 状态与回执 | 登记、原件、预览、图保存、实际显示、执行和素材保存各自如实返回；未知先查询，不自动重放，不建通用回执账本 |
| 来源追踪 | 运行关联当次实际输入、节点、软件、参数和输出；只有真实调用才保存调用事实。记忆不回写执行事实 |
| 作用域与共享 | 素材在同一workspace内供项目按实际权限引用；结果不按中间／最终分类限制，用户选择后才登记。自定义节点统一库可跨项目使用 |
| 生命周期与保护 | 沿用既有导入、校准、活动任务和原件保护；移除素材先展示工作流影响，确认后节点提示缺失。工作流专属预览随图删除，已保存完整素材不随删 |
| 比较与记忆 | 多次压缩预览关联实际运行以查看参数；完整工作文件不长期保留，旧预览不保证完整结果仍在。Agent偏好标明分析及来源项目，可跨项目参考且项目约定优先；支持编辑、停用、查看历史及恢复为当前，删除包括旧正文，不改运行事实或新增通用修订框架 |
| 保存方式 | ①少量文件、②现有业务库及科学文件、⑤唯一原生JSON图加必要运行／预览／控制信息；目录索引可重建，物理表和格式按任务确定 |

默认可复现和显式仅引用两类保证继续保留，准备失败不降级；已有固定托管输入不重复复制，科学文件与压缩预览分离。省略、null、0沿用原语义。长期外部处理不持有数据库事务等待。

<a id="handoffs"></a>

## 4. 公开交接

| 交接 | 必要保证和失效影响 |
|---|---|
| ① ↔②③④⑤ | 配置、认证、实际运行和维护事实；未知不能当空闲，控制结果先核对 |
| ② ↔⑤ →③ | 提供固定科学输入和当前纠正资料，⑤记录本次实际采用；缺失或变化明确，不用预览代替 |
| ③④ ↔⑤ | 软件及节点就绪、实际定义和更新差异；确认影响后更新，运行中内容不被替换；②登记所选完整结果 |
| 原生／接入层 ↔⑤ | 调用原生保存、编辑、转换、调度和事件；⑤核对活动目标及当前控制，返回真实保存／显示／执行结果 |

⑤内部的编辑、执行与交互由同一业务模块协调。精简MCP、Skill直达、混合Top10及显式关键词降级继续跟踪；目录派生自所属能力，不新增身份、角色或版权体系。

## 5. 场景覆盖

四类详细场景和原有十条旅程以[现行需求](../../requirements/README.md#3-关键用户旅程)为准：导入与整理归②；选择或拖入科学数据、三种处理起点、Agent接续／接管和实际处理由⑤连接②③④。Python及复合仍S6，行星从原始视频开始但具体支持范围需真实适配。

核对：项目重开与另存、固定素材组与资料修正、移除素材提示、各已执行图像节点自动预览、多次效果查看、切图暂停且后台结果归原图、人工明确交回、取消／断连核对、选择完整结果及跨项目偏好。无网页对工作流只查询，不新编辑或提交运行；②导入、③安装等非画布操作按所属规则提供。读取不恢复已撤销控制，手动变化后安静等待下次交互。

## 6. 已确认决策与待实施内容

| 决策 | 当前结论 |
|---|---|
| D1 公共控制保存 | 文件保存最新配置、当前运行信息及最近启停结果；不建配置历史或搬迁服务 |
| D2 结果登记 | 只有用户选择的完整结果入素材库，不自动登记中间文件，不按中间／最终分类限制 |
| D3 资料修正 | 新运行自动使用修正资料并记录，过去运行不改；选定素材组范围不自动增加 |
| D4 工作流／运行／交互 | ⑤统一负责；唯一当前原生图、运行记录、多次完成预览及当前控制；重要方案另存，无永久逐编辑历史 |
| D5 在线交互与预览 | 首版Agent依托活动网页，切图暂停后续写／提交；已受理继续。实际执行图像节点自动预览，后台预览归原图 |
| D6 第④阶段落位 | ④定义保存workspace JSON；⑤项目／运行／预览关联保存现有SQLite；原生连接承接命令和回执，单个平台节点包白名单加载；软件变更网页确认，外部内容接纳沿原素材新增记录且仅显式更新引用 |

文件变化确认、原生保存与项目联动、当前控制检查、软件调用、目标执行转换、科学缓存、自动预览及精简MCP都需实际实现／验证。本页不重复第④阶段已明确的必要字段、存储落位和API；具体签名／文件／测试见[详细设计](../../api/platform-contracts.md#file-design)，远期模型、算法和索引后端仍待对应任务。当前规则由现行需求和ADR说明。
