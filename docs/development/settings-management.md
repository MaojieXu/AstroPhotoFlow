# 设置记录管理

项目、设备、使用组合和组合内拍摄预设沿用素材库的操作习惯：名称搜索、按需筛选、多选、移入回收站、恢复，以及提交预览后永久删除。新增和修改继续使用表单输入；不提供设置文件导入。

主列表只展示当前记录。删除使用“移入回收站”，不会直接删除数据库行；在回收站中可恢复或预览永久删除。永久删除请求携带预览 fingerprint；依赖数量或记录变更后必须重新预览。

项目永久删除时会解除项目的单图／数据集关联并保留素材，项目拥有的素材会阻止删除。使用组合永久删除时会同时删除组合内的拍摄预设，预览会列出这些子项。

设备与素材采用快照解耦。任务接受时使用 `import_defaults_snapshot.equipment_snapshots` 按 ID 冻结设备资料；重试和恢复沿用原快照。素材当前参数保存设备 ID 和设备名称、型号、序列号、规格、备注的快照；各素材版本的 `capture_snapshot.equipment_snapshot` 保存版本事实。永久删除设备会清空版本表中的设备外键，但保留素材参数及快照。使用组合中引用该设备的注册组件会转换为组合内设备快照，拍摄预设不再向导入任务提交已删除设备 ID。

旧版 CaptureProfile 的入口、接口、项目字段和表已彻底移除；不保留旧配置兼容。项目内单图、数据集引用在永久删除项目时解除关联，底层素材与数据集保留。

回收站 API 位于 `/api/v1/settings/trash`。接口契约见[OpenAPI 快照](../api/openapi.json)；设备快照结构见[素材架构说明](../architecture/assets.md)。

## 手动检查

1. 在设置的项目、设备、使用组合分别新建一条记录并修改名称或说明，确认输入表单能保存。
2. 打开“筛选”，按项目目标、设备类别或组合设备类别过滤，再用名称搜索确认列表范围。
3. 进入“批量删除”，选择多条记录并移入回收站；在回收站恢复一条记录，确认其回到原分类。
4. 对无阻塞引用的设置执行永久删除预览，再确认删除；检查项目关联只被解除、底层素材仍存在。永久删除设备后，素材列表仍应显示原设备名称与规格快照。
5. 接受上传后，在上传完成或素材登记前永久删除设备，再完成上传并启动导入，确认素材和设备历史资料保留。
6. 同一设备改名前后分别导入图片，确认每张显示自己的历史名称；打开使用组合或预设修改草稿，确认筛选操作禁用，保存或取消后恢复。
