# 设备与组合删除

设备及组合使用同一预检／删除能力，素材继续使用回收站和原件保护。独立拍摄预设已取消，不再作为删除目标或级联对象。

- 先查询准确对象与revision，预检返回实际关联影响和指纹；指纹不代替用户授权。
- 确认后采用同一选择和指纹执行。revision或影响变化返回冲突，不自动重试或扩大范围。
- 删除设备时清理当前组合中的对应成员，保留其他成员身份及顺序；不自动换用另一设备或滤镜。
- 删除组合不删除独立登记设备，也不删除图像和科学原件。
- 当前及历史素材、固定版本、已受理任务保留设备冻结事实；取消预设不改变这条边界。
- 项目及素材的回收站、恢复和永久清理仍使用已有能力，不能绕过引用或活动任务保护。

请求类型和响应以[生成API／MCP目录](../api/README.md)为准，Agent流程见[操作指南](library-agent-tools.md)。验证见[验证记录](test-matrix.md#library-simplification)。
