# 设备管理与直接删除

素材库“导入”旁的“设备管理”默认展示设备组合，另有我的设备。相机、望远镜、滤镜、赤道仪和配件按类别选用或就地新增；新设备先保存到设备库，再加入组合草稿，取消组合仍保留设备。原有组合内设备继续保留并可编辑，新建流程不再创建仅属于组合的设备。

设备管理内容区最大640px，列表约48px一行；表单统一使用原生md弹窗（最大576px、85vh），正文可滚动，标题和操作区固定。输入框、选择器及普通按钮32px，控件最大320px。组合采用五行搜索多选，新增／组合内设备编辑在同一弹窗切换，不展开长表单。组合和预设保持整组保存；我的设备新建和编辑共用EquipmentFields输入表单，编辑预填数据、固定类型，点击保存统一提交改动字段。

“我的设备”单击选中记录后，仅在该行右侧显示“编辑”按钮，点击打开与新建相同的表单；切换选中设备后按钮随之移动，列表下方不再显示编辑按钮，设备行双击不打开弹窗。按钮沿用原生键盘操作，不再显示列表下方的设备详情。表单为取消／保存操作，不再逐字段自动保存；沿用revision冲突及失败输入保留，未修改规格保持原值，未保存关闭先确认。保存成功刷新列表并保留选中。勾选框仅用于删除选择，不打开弹窗，删除继续通过选择后的影响确认完成。

我的设备采用简洁列表：普通行透明、无卡片边框，悬停轻微强调，选中行保留主题背景及侧边色标，键盘焦点单独描边。名称、类别及有区别的型号保持可见，型号与名称相同（忽略首尾空白和大小写）或为空时省略重复副标题。长名称与副标题省略，行右侧预留编辑按钮宽度，切换选中不挤动文字。选择、勾选删除、表单及设备组合表格不变。

两个页签共用精简工具栏：搜索与唯一的新建按钮放在同一行，刷新和“批量管理”进入原生更多菜单；组合不再显示筛选按钮或重复标题，我的设备直接选择类别。默认隐藏设备／组合的行选择框及表头选择列，不保留空占位。进入批量管理后显示原生复选框、已选数量、全选当前页、删除所选和完成；零勾选禁用删除，取消最后一项仍保留模式，完成才退出。搜索、分页、排序或切换页签清空勾选并退出，原有影响预览及确认保持。设备管理固定每页50条，仅多页显示分页；素材库偏好保持。空状态不显示计数／分页，刷新后空末页回到有效页。

宿主通过LibraryControls注入原生Button、Menu、Checkbox和Tabs，包内通过薄适配消费；UI包不导入宿主源码，不新增依赖或存储。设备行首圆圈替换为Lucide类别图标，普通、悬停、选中及页签状态采用原生主题语义色。独立测试入口保留已有HTML控件路径。

组合以名称、相机、望远镜、赤道仪、滤镜和光学附件六列表格显示，未配置用 `—`，同类多件悬停文字查看完整名单，历史成像系统在望远镜列标明。各列表头可升降序排序，先在服务端完成排序再分页；空列始终排最后。排序清空勾选并回第一页，未保存或正在保存时不可排序。选中组合后并排显示“新建拍摄预设”和“编辑设备组合”，下方保留已有预设；编辑打开现有组合表单，删除组合继续在更多菜单，不再重复显示设备清单。表格内部横向滚动，不改变我的设备或素材库布局。

设备管理页签、表格及组合表单不再显示ⓘ图标。组合可多选滤镜，预设在所属组合的注册滤镜中选择一片或沿用组合默认值。预设展示可选名称前缀、滤镜、温度、曝光及ISO／增益，增益模式增加Offset；完整名称自动追加上述已填写参数。其他旧字段仅隐藏，修改可见字段不清除其已有值，保存、冲突及草稿保护规则保持。

设备、组合和预设使用单次删除确认，不经过回收站；支持单条及批量选择。确认前由服务返回实际影响，显示受影响组合、预设及保留的素材快照；记录或关联版本变化后必须重新读取影响，不能使用过期确认。

删除设备从所有组合移除注册设备关联，清除预设中对应设备默认值，不保留可继续使用的组合内副本。素材当前资料及固定版本保留历史设备快照，版本外键解除；已受理导入、恢复和重试沿用任务接受时冻结的设备资料。删除组合同时删除所属预设，保留独立设备；删除预设保留组合及设备。

接口为 `POST /api/v1/equipment-management/delete-preview` 与 `/delete`。请求 `items` 含 `entry_type`（equipment／equipment_setup／capture_preset）、`id` 和 `revision`；删除再携带当前 `preview_fingerprint`。冲突返回409，不自动重试。项目不属于这个直接删除接口；项目数据、固定素材引用和公开接口保留，本模块不再提供项目页面。旧设置回收站 API 保留原有归档记录和项目语义，不作为新设备删除流程。

## 手动检查

1. 在设备组合中分别新增五类设备，确认我的设备可查询，并能加入另一组合；取消组合时已保存设备仍存在。
2. 保存失败保留设备输入；草稿切换确认可取消，旧组合内设备可继续编辑。
3. 对设备、组合和预设分别执行单条或批量删除：先查看影响，取消不删除；确认只发送一次删除请求。
4. 删除被组合／预设引用的设备，确认关联及默认值清理，已有素材、固定版本和已受理任务保留原设备快照及原件。
5. 预览后修改被影响组合或预设，旧确认应返回409；删除组合时列出并清理所属预设，独立设备仍可使用。
