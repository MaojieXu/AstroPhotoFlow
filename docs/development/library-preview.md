# 单图预览与缓存

素材库、组内照片、项目单图引用和项目固定组成员均可打开预览。列表缩略图最长边 100 px，大图 JPEG 最长边 1080 px，不放大小图。科学原件与显示缓存分开，缺失预览不表示原件丢失。

## 网页行为

预览对话框表达加载、未就绪、失败和不支持状态，支持显式重试及按钮／背景／Escape 关闭。关闭后释放图像 URL 与轮询，迟到响应不能重新打开；未保存或保存失败的资料仍受离开保护。

项目固定组按引用版本的成员分页，不替换为集合或资产当前版本。组内浏览、参数编辑、排序、分页和删除继续保留，不再提供重复的管理成员入口。

网页打开单图时从原件计算自动配方：RGB 估计背景白平衡后使用统一 MTF 曲线，Mono 只拉伸。配方属于所选固定版本及 HDU，保存算法、偏移、通道系数、阴影／高光和中间调；同一事务发布大图与缩略图。其他成员、原件及科学参数不变。算法细节见[素材说明](../architecture/assets.md)。

## 调度与读取接口

共享作用域为 `/api/v1/library/assets/{asset_id}/versions/{version_id}/previews`；项目作用域为 `/api/v1/projects/{project_id}/asset-references/{reference_id}/previews`，解析项目固定版本并检查归属。

| 方法与后缀 | 行为 |
|---|---|
| POST `/display` | 用已保存配方调度或显式重试大图缓存 |
| POST `/display/auto-stretch` | 单图自动配方及缓存；已有结果复用，不强制重算 |
| GET `/display/status` | 查询状态，不启动任务 |
| GET `/display` | 只读取可用缓存 JPEG，不隐式生成 |

调度生成中返回 202，否则返回 200。状态为 `not_ready`、`generating`、`available`、`failed` 或 `unsupported`，包含固定版本、尺寸、错误及 stretch 结果；字段以[OpenAPI](../api/openapi.json)为准。失败缓存保留错误，显式调度可重试。

## 配方、并发和生命周期

缓存按固定版本、HDU、尺寸和算法版本定位。已有可用文件直接复用；同一版本生成时复用任务。使用服务共享预览线程池，遵守 preview_workers，不为单次请求创建解码线程池。

普通大图调度使用已保存配方；网页自动配方独立保存。已保存数值不依赖历史参考照片仍然存活，重建直接使用配方，不能从拉伸 JPEG 反推。等待旧配方任务的网页会在其完成后补齐自动配方。

元数据重试在同一事务将缩略图缓存标为 pending；旧 JPEG 即使仍在磁盘，也不作为可用配方。实际缓存状态决定可用性，不使用历史导入任务的 unsupported／failed 结果代替当前缓存。回填有效预览不改写历史任务和人工参数。

RAW 按请求尺寸选择内嵌或解码图像，不拿小封面冒充大图；SER／视频沿用首帧预览规则。XISF 等格式仍有全帧解码成本。

## 清理保护

生成中的明确所有权阻止并发永久清理。清理已开始时拒绝新预览；发布前在写事务中重新检查版本、所有权和状态，不能在版本被删除后补写缓存。共享缓存路径、临时文件和外部原件继续受保护。

启动将中断的 generating 任务标为可显式重试的失败，退出排空正在生成的任务。缓存失败不覆盖原缩略图或配方。当前检查见[验证矩阵](test-matrix.md)，回归主要位于 `tests/modules/data/test_display_previews.py` 和 `test_auto_stretch.py`。
