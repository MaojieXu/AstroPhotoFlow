# 手动验收入口

打开 http://127.0.0.1:31388/ 后按Ctrl+F5，进入“天文”。主workspace仍为`.artifacts/workspaces/dev`，
原有38张照片保持。以下为人工交互检查，不需要重新导入整套真实素材。

1. **现有照片**：在全部素材查看原图像组，点击“图像组”进入，确认排序/搜索/资料编辑/返回仍可用。
   点击任意缩略图查看大图，检查加载、关闭、Escape。最大边上限1080px，图小不放大；首次生成后再次打开使用缓存。
2. **设置**：项目可添加单图和数据集固定版本。设备按类别登记；新建使用组合，加入已注册设备和一个手填设备。
   保存后确认手填项只在组合内，设备库没有自动多一条；编辑组合不修改注册设备。
3. **预设**：进入组合新建预设，例如Gain0、曝光120s、Offset8。预设放在组合内，旧版拍摄配置保留次级入口。
4. **小型导入**：可使用本机准备的`.artifacts/manual-input/module-20261025`两张合成FITS，Header明确标为
   Light Frame和Master Dark，曝光30s、Gain9。只导入Light并选择上述预设，检查曝光30来自文件、Offset8来自预设；
   若人工填Gain0，应保留0。省略分类自动识别，勾选“手动指定整批分类”则按所填字段覆盖。
   导入进度先完成登记；文件托管/预览在后台，原件未就绪时有明确状态。
5. **校准库**：导入Master Dark样例，进入校准库，从已有校准照片创建逻辑校准组并填写场景说明。
   不会复制现有照片或改动原分组。Light与Master Light在亮场视图，未知/混合数据仍能在全部素材找到。
6. **绑定**：把`.artifacts/manual-input/module-20261025/light-only`按文件夹导入为单成员亮场组；打开组，选择固定Dark组版本或Master帧作为默认。
   对成员测试继承、不使用和其他版本覆盖；保存后产生新组版本，另一个组的同图不受影响。
   项目固定引用旧版本继续保持原绑定。此处只管理关系，不会实际执行校准。
7. **项目成员**：数据集项目引用的“查看固定版本”展开成员并分页；在素材库发布新版本后，项目仍查看原固定成员。
8. **删除/恢复**：只用合成样例验证移到垃圾桶、恢复、清理预览和永久删除。永久删除使用当前确认范围，
   原外部样例文件不被删除。历史校准引用会保护目标；当前解绑不会抹掉历史版本引用。

MCP现有连接如仍只显示旧五工具，重连该服务器刷新到58工具；注册文件没有改动。
命令和参数详见[CLI/MCP操作参考](library-agent-tools.md)，可复用[项目Skill](../../.agents/skills/astrophotoflow-library/SKILL.md)。
CLI预览导出使用新输出文件名，已有文件将明确拒绝覆盖。

自动检查的范围、实际结果与限制见[验收记录](module-improvements-acceptance.md)和[复查记录](module-improvements-review.md)。
