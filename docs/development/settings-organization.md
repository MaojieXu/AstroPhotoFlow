# 设置组织：设备与可选组合

有效需求以[数据与设备](../requirements/README.md#fr-04-数据素材与业务资料)为准，接口字段以[生成目录](../api/README.md)为准。

- 设备管理保留“设备组合”和“我的设备”；独立拍摄预设及其页面、接口、工具、实体已取消。
- 设备支持相机、望远镜、滤镜、赤道仪。望远镜内维护光学附件；组合允许至多一台相机、望远镜和赤道仪，以及多片滤镜。内联成员不自动登记进设备库。
- 组合仅用于快捷选择，不是导入前置条件。导入可直接选择设备，也可选组合后明确实际滤镜和附件；不从多片滤镜中猜测。
- 曝光、gain、offset、实测温度属于图像，来自文件头或本次确认的人工填写。设备关联不覆盖拍摄参数，不建立替代预设的隐藏默认参数。
- 仅应用明确字段，省略保持、允许的null清空、0保留。导入受理冻结实际选择，后续修改设备或组合不回写历史快照。
- 设备和组合删除先预检实际影响，再按当前指纹执行；素材及原件保留，见[删除规则](settings-management.md)。
- 组合表单继续保留已有成员身份及顺序；保存、取消、未保存修改确认沿用现有交互。

本轮实现与验证见[验证记录](test-matrix.md#library-simplification)。
