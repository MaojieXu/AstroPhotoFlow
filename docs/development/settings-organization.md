# 设置组织：设备组合与拍摄预设

## 已实现行为

- 选中组合后并排显示“新建拍摄预设”和“编辑设备组合”，下方显示已有预设，不重复展示组合名称、设备数量或清单；编辑打开现有组合表单，“更多”仅保留刷新及删除组合。单件规格继续在“我的设备”编辑。设备管理页签、组合表格及组合表单移除ⓘ图标，表格完整设备名称直接通过悬停文字查看。
- 拍摄预设表单只读展示所属组合；编辑滤镜、曝光、温度、参数模式及当前数值。ISO模式显示ISO，增益模式显示Gain＋Offset，常规与未设置分别保留。相机、望远镜和附件直接继承组合，不提供独立覆盖；不再编辑名称前缀、分类或备注。专用参数契约只接受上述字段。
- 组合允许零或多片滤镜（注册或组合内设备）；预设候选只来自所属组合，省略表示继承首片滤镜、null明确不使用、成员ID指定一片。继承选项显示实际滤镜名称／无滤镜，重排只影响未来继承解析，不改历史快照。删除指定滤镜后当前预设置为明确不使用，不能自动换用另一片。
- 预设名称由后端统一按组合名、实际滤镜、曝光、温度及有效模式参数生成；新建时提示保存后自动生成，编辑时可显示已有名称，只读不反向拆解前缀。不要求名称唯一，稳定ID继续区分同名预设，网页、MCP和CLI使用同一保存规则。

- 设备组合列表采用固定四列横向表格：名称、相机、望远镜、滤镜，左侧保留勾选框。缺少类别显示 `—`，滤镜逐项显示全部名称，长名称和窄栏换行，不折叠为数量或“更多”；注册设备、组合内设备均可显示，望远镜列附所选附件及有效焦距摘要。不新增表单必填项，我的设备与素材库布局不变。
- 四列表头均支持首次升序、再次降序及方向提示；初始仍按创建时间倒序。组合排序与素材库独立，服务端先排序再分页；切换排序回到第一页并清空勾选，未保存草稿及保存期间禁止排序。滤镜长名称完整换行，其他设备长名称可省略显示，表格仅在自身区域横向滚动。

- 素材库右上的“设备管理”入口默认展示设备组合，另有我的设备；项目页面从该模块移出，既有项目数据与接口保留。仅支持相机、望远镜、滤镜，类别均为可选；取消赤道仪与独立配件。望远镜内部附件仅填写名称与有限正数倍率，允许1×，内部身份用于稳定引用。组合中的望远镜一次选一个附件或不使用；预设直接继承组合附件。有效焦距由后端从原生焦距和实际倍率计算，未知焦距显示未知，1×附件仍保留名称。
- 新建组合在原生md限宽弹窗中相机和望远镜采用可清除单选，滤镜多选，选择直接更新组合草稿，不再单独点击加入。新建及编辑组合内设备在同一弹窗切换，返回保留组合草稿；已有相机／望远镜时“保存设备并替换”先登记设备，再明确替换组合草稿中的成员；未占用时保存并加入；取消组合不删除已登记设备，并直接显示保存提示。单件设备可跨组合复用。
- 使用组合可以关联注册设备，或保存只属于该组合的内联设备。编辑组合不会改写注册设备，也不会把内联设备登记进设备库。
- 拍摄预设在所属组合内创建和编辑，删除先展示影响，再直接删除，不经过回收站。预设参数保持稀疏结构：未触碰字段不写入；清空已填写字段传 `null`；数值 `0` 保留。
- 设备组合和我的设备统一精简工具栏：保留搜索与单个新建按钮，刷新放入“更多”，设备类别在我的设备页直接选择；组合不再显示筛选按钮和重复标题。列表勾选后显示批量删除，固定每页50条，仅多页显示分页。拍摄预设仍在组合详情内维护；单条及批量删除规则保持，新增和修改继续使用输入表单，不提供设置文件导入。
- 永久删除设备时，素材当前参数和固定版本保留设备快照，设备外键解除；直接删除时从关联组合移除该设备，并清除预设中对应设备默认值；不创建组合内副本。旧设置回收站接口仍保留原有项目及历史归档语义。接受后的导入任务独立保留设备资料，设备永久删除不会导致后续登记或重试失败。
- 旧版 CaptureProfile 已移除，包括旧入口、接口、项目字段和数据表；配置统一使用设备、使用组合、拍摄预设。0001–0008 为历史迁移，0009 移除旧结构，不转换旧配置为新预设。
- 项目固定版本引用的业务语义、数据和公开接口保留；设备管理不再展示项目页面，本轮不新增其他项目入口。
- 导入对话框先选组合再选所属预设，只提交 `capture_preset_id`，不把默认值填入人工表单。接受任务时由公共 `capture_defaults_snapshot` 保存配置快照，重试沿用原快照；人工／文件／预设的最终优先级由共享导入流水线计算。
- 组合和预设表单有未保存修改时，切换区域／记录会确认；搜索、筛选、分页与刷新在保存或取消前停用。

模式切换保留稀疏草稿及已存非活动数值，实际导入默认参数只采用当前模式有效值；常规和未设置不应用隐藏的ISO／Gain／Offset。清空Offset传null，数值0保留。滤镜恢复继承时省略selection.filter，明确不使用才传null；PATCH省略整个选择对象不修改，提供对象则替换稀疏选择。

## API

| 方法 | 路径 | 用途 |
|---|---|---|
| GET / POST | `/api/v1/equipment-setups` | 分页查询／创建组合 |
| GET / PATCH | `/api/v1/equipment-setups/{setup_id}` | 读取／更新组合 |
| GET / POST | `/api/v1/equipment-setups/{setup_id}/presets` | 查询／创建组合内预设 |
| GET | `/api/v1/capture-presets` | 跨组合查询，可按 `equipment_setup_id` 筛选 |
| GET / PATCH | `/api/v1/capture-presets/{preset_id}` | 读取／更新预设 |
| POST | `/api/v1/equipment-management/delete-preview` | 读取设备／组合／预设的实际删除影响 |
| POST | `/api/v1/equipment-management/delete` | 校验 revision 与预览 fingerprint 后直接删除 |

列表沿用 `limit/offset/q/status/sort_by/order`。更新需要 `base_revision`，冲突返回 `409 REVISION_CONFLICT`；不存在对象为 `404 RESOURCE_NOT_FOUND`，错误设备关联为 `422 INVALID_REFERENCE`。预设参数和分类 PATCH 合并明确提供的字段，状态通过归档管理。后端 DTO、前端 Zod、代理白名单和生成的 OpenAPI 同步更新。

组合 `sort_by` 可用 `created_at/name/camera/telescope/filter`；设备列比较组合内顺序拼接的完整设备名称，空列始终最后，同值按组合名称及ID稳定排序。原有 `component_kind` 按实际设备类型过滤。

回收站、设备快照与当前手动检查见[设置记录管理](settings-management.md)，导入优先级见[导入流水线](import-pipeline.md)，验证证据见[验证矩阵](test-matrix.md)。


附件编辑保留内部身份，组合／预设不得引用其他望远镜的附件。删除或变更被使用的附件必须明确处理当前引用，不能静默换用别的附件；已接受导入与运行快照保留当时名称、倍率及焦距。预览使用新的隔离workspace，不自动重写旧用户数据库。


### 设备表单精简与分区

设备仅维护名称、型号、类型对应参数和备注，不再维护序列号；望远镜参数删除口径，相机删除sensor_mode，仅以cfa_pattern作为像素排列来源。像素排列的未指定与单色分别表达，既有明确排列不被推导覆盖。设备类型为三项紧凑无搜索单选。

表单按基本信息、设备参数、望远镜附件、备注组织，统一内容宽度及标签样式，单位独立显示且不换行；附件使用名称、倍率、移除同一栅格。注册设备和组合内设备共用表单。历史快照可保留当时记录的退役字段，不能因此恢复可编辑入口；原始科学文件头不删改。现有预览数据离线备份后更新，不清空设备、组合、预设或素材。

组合数量上限跨注册和组合内来源合计计算，含新建加入与内联改类型；前端提示与后端事务内校验同步。超过数量的旧组合或含真实旧预设覆盖的数据须先列冲突，不自动选第一台或删除。历史快照契约与当前编辑契约独立维护。像素排列为固定枚举，使用紧凑无搜索单选。


### 滤镜通道与显示

滤镜Channel只能通过文本框手填，允许自定义及复合标签；空白清除为未指定，不提供选项、不从名称猜测、不自动改写大小写。名称与型号继续标识实际滤镜，带宽为可选正数nm。当前组合标签统一显示“Channel＋带宽”（例如Ha 7nm）；未知时显示“未指定通道＋可选带宽 · 原名”。所有成员标签完整显示，不按通道去重；原名保留辅助提示。

组合及预设的滤镜候选共用标签格式，显示“Channel＋带宽 · 实际名称”，选择值始终为设备／成员身份；默认滤镜同样显示可辨认的实际候选。我的设备继续主显原名，预设保存名称仍由后端使用实际滤镜原名生成。原始FITS FILTER不替换，已有快照不回写，新通道资料随后续快照冻结。

滤镜列以首个显示成员的通道、数值带宽排序，再按完整原名摘要及稳定身份确定顺序，未知通道／带宽及空组合放后；同通道多片仍分别显示。Channel保存在既有类型化specs JSON，不增加独立通道表或运行时转换，旧JSON不补值。
