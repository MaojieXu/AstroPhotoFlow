## 2. 独立资产服务与数据库

当前调用链：

```text
ComfyUI 前端 → ComfyUI 同源代理 → 独立 FastAPI 资产服务 → SQLite
```

已完成：

- FastAPI、Pydantic 服务及接口契约。
- SQLAlchemy 数据模型。
- Alembic `0001 → 0005` 数据库迁移。
- 独立于代码仓库和 ComfyUI 安装目录的数据目录。
- 本机配置文件、服务令牌、健康检查和能力查询。
- OpenAPI 接口快照及前端 Zod 数据校验。
- revision 并发保护，拒绝旧资料覆盖新资料。
- 统一错误结构、错误代码及请求 ID。
- 数据库服务与迁移进程互斥锁。
- 显式升级已有数据库，升级前生成 SQLite 一致备份。
- 数据库状态查询、启动、升级和预览补齐命令。

数据库包含项目、设备、拍摄配置、资产、资产内容记录、数据集及成员版本、项目引用、导入任务、逐文件结果、FITS 元数据、预览和素材库入口移除记录。

## 3. 项目管理

- 创建、查询、编辑项目。
- 管理项目名称、目标名称、备注。
- 项目归档及恢复。
- 关联、替换、清空项目的拍摄配置。
- 为项目选用共享素材或数据集。
- 移除项目引用，保留共享素材及文件。
- 项目固定引用指定内容记录或数据集成员版本。
- 项目页面显示资产最新的分类、参数和备注。

目前完成的是资产管理所需的项目基础，尚未统一组织工作流、运行记录、Agent 会话和项目记忆。

## 4. 设备与拍摄配置管理

设备支持相机、成像系统和滤镜，已实现创建、查询、编辑、归档和恢复，以及对应规格字段。相机支持登记传感器、尺寸、像元、位深和 CFA 等信息。

拍摄配置支持：

- 关联相机、成像系统和滤镜。
- 设置帧用途。
- 设置 Standard／ISO／Gain 等参数模式。
- 设置曝光、ISO、Gain、Offset、温度和 Bin。
- 名称、备注、归档与恢复。
- 被项目关联使用。

修改设备或拍摄配置默认值，不会自动改写已有资产资料。

## 5. 共享素材库

已采用本机单用户、跨项目共享素材库：

- 素材无需先归属某个项目。
- 项目通过引用选用共享素材。
- 独立素材和数据集统一展示。
- 简洁、详细两种列表模式。
- 单击选择、双击原位编辑。
- 缩略图及详情预览。
- 搜索、筛选、排序和分页。
- 批量选择、批量移除素材库入口。
- 加载、空库、服务不可用、请求失败等状态展示。

资产保留内部内容记录身份；当前分类、拍摄参数和备注直接编辑，不建立图像资料修订历史。

## 6. 文件导入与存储

前端已支持：

- 使用系统文件选择器选择单个或多个文件。
- 使用系统文件夹选择器导入文件夹第一层素材。
- 浏览器向本机资产服务上传文件。
- 上传进度和后台处理进度展示。
- 导入时填写分类、拍摄参数和备注。
- 单文件形成独立资产。
- 多文件、文件夹形成数据集；单成员文件夹仍形成数据集。

服务端另外支持配置导入根目录，在允许范围内浏览、引用原文件或复制为托管文件。

导入规则：

- 导入时计算 BLAKE3。
- 同批重复来源只登记一次。
- 不同批次导入同一文件，独立创建资产。
- 不跨批次按路径或散列复用资产。
- 原始文件不被修改。
- 内容成功入库后，解析或预览失败仍保留资产，并单独记录问题。
- 零成功内容不发布空数据集。
- 素材列表和进入项目时不扫描、重算散列或检查所有原件。
- 实际需要读取文件时，再报告缺失或不可读。

前端选择文件采用上传托管；服务端引用导入保留原路径，两种入口的存储方式有所区别。

## 7. 资产分类、参数与备注编辑

| 类别 | 已支持内容 |
|---|---|
| 基本资料 | 名称、多行备注、状态 |
| 分类 | 素材形态、帧用途 |
| 设备关联 | 相机、成像系统、滤镜 |
| 拍摄参数 | 参数模式、ISO、Gain、Offset |
| 曝光与温度 | 单帧曝光、累计曝光、实测温度 |
| 图像采样 | Bin、CFA |

已落实的规则：

- 人工明确填写的值优先。
- 原始 Header、解析结果和人工值分别保留。
- 编辑时明确清空字段，就保持为空。
- 零是有效值，未知值保持空值。
- 分类变化时同步派生用途及校准级别。
- Master Light 作为输入素材管理。
- 编辑资料不会新建资产内容版本。
- 支持数据集成员参数批量更新，并进行 revision 校验及事务保护。
- 数据集参数展示区分一致、混合、部分缺失和未指定，不拿封面参数代表全部成员。

## 8. 数据集与项目引用

- 批量导入生成数据集。
- 数据集名称、备注、状态编辑。
- 查看及编辑成员。
- 增加或移除成员时创建新的成员版本。
- 保留旧版本成员集合。
- 保留已有成员顺序，新成员追加。
- 项目固定引用指定数据集版本。
- 移除成员或项目引用时保留资产原件。

资产资料更新会显示在引用页面中，但不会改变已经固定的数据集成员集合。

## 9. 搜索、筛选、排序和分页

已实现服务端对完整匹配集合先筛选、排序，再分页。

筛选内容包括：

- 素材形态、帧用途、用途分类。
- 相机、成像系统、滤镜。
- 参数模式、Bin。
- 曝光、累计曝光、温度、ISO、Gain、Offset 范围。

其他已完成行为：

- 数据集组合筛选要求同一成员满足组合条件。
- 支持名称、分类、设备、拍摄参数、时间等字段排序。
- 支持 10／20／50／全部的分页选择。
- “全部”模式分批读取服务端页面。
- 搜索或筛选变化后重置分页。
- 旧请求响应不能覆盖新查询。
- 保存期间触发的查询会排队。
- 保存失败时保留草稿和待查询。
- 取消编辑或重试成功后加载最新查询条件。
- 筛选面板支持范围滑块及尺寸调整。

## 10. 格式、元数据和预览

| 格式 | 入库 | 当前解析／预览 |
|---|---|---|
| FITS：`.fits`、`.fit`、`.fts`、`.fits.fz`、`.fit.fz` | 支持 | HDU、Header、Mono／Bayer／明确 RGB 预览 |
| JPG、JPEG、PNG、TIFF、TIF、BMP、WebP | 支持 | 两档 JPEG 预览 |
| SER | 支持 | 首帧静态预览 |
| MP4、MOV、AVI、MKV | 支持 | 通过系统 FFmpeg 生成首个可解码帧预览 |
| 相机 RAW | 支持 | 暂无解析／预览 |
| XISF | 支持 | 暂无解析／预览 |
| NumPy `.npy`／`.npz` | 服务端支持入库 | 暂无数组解析／切片预览 |

浏览器文件夹入口只选择第一层常规图像、FITS、RAW、XISF 和视频，忽略子文件夹及其他格式。格式识别依据扩展名，不代表文件内容一定有效。

FITS 已完成：

- 保存各 HDU 描述及原始 Header 卡片。
- 保留重复 COMMENT／HISTORY 顺序。
- 保存数值类型、形状、BITPIX、BSCALE、BZERO、BUNIT。
- 自动选择首个受支持图像 HDU；其预览失败时不回退尝试后续 HDU。
- 支持 `RGGB`、`BGGR`、`GRBG`、`GBRG` 四种 Bayer 排列及人工 CFA。
- RGB 需要明确通道轴信息，不猜测一般三维数组为 RGB。
- X-Trans、Quad Bayer 可登记元数据，尚不支持马赛克解码预览。
- Header 分类信息保留为来源信息，不覆盖人工分类。
- `CCD-TEMP` 作为设定温度解析，不填入人工实测温度字段。

预览统一提供：

- 缩略图最长边 100 px。
- 详情图最长边 1024 px。
- 保持比例，不放大小图。
- 在 ComfyUI 内打开详情浮层。
- FITS 使用固定 `auto-stretch-1` 显示预设，记录显示算法信息。
- 异步预览请求失效保护，避免旧请求覆盖或重新打开已关闭浮层。
- 缺失预览补齐命令；不重导入或覆盖可用预览，单项失败后继续后续素材。

目前是显示预览，还没有完整图像查看器、视频播放器或逐帧分析。

## 11. 导入任务与异常恢复

服务端已实现：

- 持久化任务及逐文件处理结果。
- 分别记录内容、元数据和预览状态。
- 排队、运行、取消、中断、成功和失败等状态。
- 服务中断后识别未完成任务。
- 用户恢复时继续原任务 ID。
- 对符合条件的失败项创建关联重试任务。
- 成功阶段不重复登记资产或重新处理。
- 取消时保留已经完成的内容。
- 数据集发布冲突时保留已成功资产及错误报告。

前端已接入行内进度、失败提示及中断任务继续导入。浏览器上传中断时仍需要重新选择文件；已进入服务端处理的任务按任务恢复逻辑继续。

**待对齐事项：数据集发布 revision 冲突后的完整错误报告和“手动补入数据集”恢复 UI 尚未形成完整闭环。** 服务端保留相应资产和报告，但旧文档中的相关 UI 验收描述不能作为当前界面已完成的证据。

## 12. 删除与原件保护

目前“删除”按不同对象区分：

- 配置记录支持归档和恢复。
- 项目中可移除资产或数据集引用。
- 素材库支持批量隐藏入口。

素材库批量移除：

- 整批校验 revision 和数据集当前版本。
- 成功时只移除素材库可见入口。
- 保留原始文件、托管文件、资产及版本记录。
- 保留数据集成员和项目引用。
- 数据集移除记录固定当时的成员版本，避免后续成员变化影响原移除范围。

尚未实现存储清理和物理文件删除管理。

## 13. 自动启动、监控与访问控制

ComfyUI 加载扩展时：

- 复用已认证且健康的资产服务。
- 或通过 uv 启动独立服务。
- 使用锁定环境，不自动安装依赖。
- 最多等待 20 秒就绪。
- 每 5 秒进行健康检查。
- 连续三次健康检查失败后明确报告不可用。
- 扩展管理的进程异常退出时最多自动重启一次。
- 关闭时只停止自己启动的服务进程。

访问控制：

- 服务绑定本机回环地址。
- 浏览器通过 ComfyUI 同源代理访问。
- 令牌由后端持有，不发送到浏览器。
- 代理只开放明确登记的接口。
- 校验请求来源和导入路径边界。
- 已有数据库升级必须显式执行；新数据库首次启动时初始化。
