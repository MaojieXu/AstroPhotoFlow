# 素材库

[English](library.en.md) | 中文

素材、集合、项目引用、设备、校准、已检查结果与回收站的行为归 data 模块；模块职责与数据归属见[架构](../architecture.md)，产品规则见[数据产品需求](../product/data.md)。

## 素材与数据集

- 素材以 asset_id 保持稳定身份和一份登记原件，资料编辑使用 revision；参数区分未提供、显式 null 与 0，过期 revision 拒绝覆盖。原件内容变化时阻止科学读取，恢复登记内容或重新导入后再使用。
- 数据集以 dataset_id 保存当前有序成员；编辑只增减明确成员，保留其余顺序与校准绑定，移除成员保留素材原件。
- 项目引用素材与数据集身份；数据集编辑对所有引用生效，调用开始时固定本次实际输入。
- 登记、原件可用、元数据与预览分别表达，预览不成为科学输入。

## 磁盘与说明文件

- `data/library/` 按用途、Subframe／MasterFrame 和三种校准状态形成固定分类矩阵。未知用途归 Unclassified，其他形态归其 Other。目录规则由 `src/astrophotoflow/modules/data/library/layout.py` 维护。
- 每个数据集使用 `<数据集名称>__<设备与拍摄参数>__<短ID>` 目录，导入文件与固定 `dataset.json` 直接同放其中。每个素材最多归属一个数据集，说明文件记录素材 ID 与相对 library 的原件路径。目录标签采用首个当前成员的参数，JSON 展示完整参数差异与未知数量。独立子帧、Master 各有独立目录，Master 条件目录省略 Dark／Bias／DarkFlat 的滤镜字段。
- 名称保留原文件名、实测温度与曝光的小数，未知写 UNK。短 ID 从 8 位增加到无冲突长度。Windows 非法字符、保留名称、路径长度与链接边界统一校验。
- SQLite 保存当前事实。数据库提交后原子发布 JSON，列出有序成员、状态依据、待用 Master 和已执行处理摘要。失败保留已提交资料并暴露待更新或失败状态，重建按当前 revision 从数据库发布。
- 资料修改先保存数据库。显式整理目录先检查完整移动范围、哈希、冲突及活动任务，按预检令牌执行并保存逐文件回执。新文件入口建立并提交实际位置后清理旧入口，中断时按原件身份核对。未知结果通过请求 ID 查询。

## 设备与组合

- 设备分相机、望远镜、滤镜与赤道仪；望远镜内部维护光学附件，不是独立设备类别。
- 组合至多一台相机、望远镜、赤道仪与多片滤镜；内联成员不自动登记设备库，组合只是快捷选择，不是导入前置条件。
- 导入受理时冻结设备信息为导入快照；修改或删除设备库不回写快照，永久删除只解除外键。
- 曝光、gain、offset 与实测温度属于图像，来自文件头或人工确认，设备关联不覆盖。

## 校准

- 数据集按用途保存唯一当前校准绑定，科学输入解析对组内所有子帧使用同一配置。
- 校准目标是与槽位用途一致的 Master 素材。原始集合可记录为 Master 的来源。用户明确选择目标，保存绑定只记录关系。单图校准和 Master 人工来源保存当前状态，已开始调用保留实际采用的关系与资料。
- Master Light 属于亮场；校准库与亮场视图独立，未知用途仍可从全部素材访问。
- Light 可选暗场、平场与 Bias，Flat 可选 Bias 与暗平场，Dark 与 Dark-flat 可选 Bias。
- 校准变化更新当前数据集并增加 revision。追加前按当前组的绑定检查新成员，拍摄参数差异返回 warning，已开始的调用使用原有输入快照。
- 组曝光汇总只累加 subframe 的 `exposure_seconds`，不加入 integration 时间或 Master，并区分已知与未知数量。

## 结果与导出

- 已检查结果归 `src/astrophotoflow/modules/data/results/`；Data 节点读取固定 `APF_SCIENCE` 引用或原生 IMAGE 输入，连接输入优先，冲突明确失败。
- `APF_FILE_REFERENCE` 交接坏点表、ICC、比较星 CSV、WCS 与脚本，不伪装成科学图像。
- 导出默认复制完整容器；显式格式与精度只影响副本，不隐式归一化、裁剪或开发 RAW，预览 JPEG 不是科学输入。

## 回收站与原件保护

- 移除、恢复与永久清理分别操作；永久清理先预检引用影响并返回指纹，用户确认后用同一选择与同一指纹执行。
- revision 或影响变化返回冲突，不自动重试或扩大范围；文件系统与数据库不是统一事务，部分失败保留失败项。
- 校准引用与正在生成的大图参与清理检查；仍有所选范围以外的项目、数据集、校准或来源引用时阻止清理，预检列出影响。清理与软件调用、导出及目录整理共用任务准入，检查实际输入和辅助校准占用。
- 进入回收站的对象不能新增项目、成员、校准或人工来源关系。资料编辑在事务中检查受影响校准结构，失效时返回消费者与槽位。删除设备保留导入快照，并对受影响素材各推进一次 revision 和更新时间。

## 对外契约

- HTTP 路由在 `src/astrophotoflow/interfaces/http/data/`（素材、集合、项目、设备、校准、结果、导出与回收站）。
- 契约模型在 `src/astrophotoflow/contracts/`，字段以 [OpenAPI 快照](../api/openapi.json) 为准；查询入口见[参考](../references.md)。
- 公开入口是 `src/astrophotoflow/modules/data/public.py`；其他模块不读本模块私有 ORM。
