# 素材库

[English](library.en.md) | 中文

素材、集合、项目引用、设备、校准、已检查结果与回收站的行为归 data 模块；模块职责与数据归属见[架构](../architecture.md)，产品规则见[数据产品需求](../product/data.md)。

## 素材与固定版本

- 素材有稳定身份、版本与 revision；参数区分未提供、显式 null 与 0，过期 revision 拒绝覆盖。
- 集合版本固定成员范围与顺序；编辑只增减明确成员，保留其余顺序与校准绑定，不删除素材原件。
- 项目引用固定到素材或集合版本，不关联工作流文件；已选旧版项目保持原版本。
- 登记、原件可用、元数据与预览分别表达，预览不成为科学输入。

## 设备与组合

- 设备分相机、望远镜、滤镜与赤道仪；望远镜内部维护光学附件，不是独立设备类别。
- 组合至多一台相机、望远镜、赤道仪与多片滤镜；内联成员不自动登记设备库，组合只是快捷选择，不是导入前置条件。
- 导入受理时冻结设备信息为版本快照；修改或删除设备库不回写快照，永久删除只解除外键。
- 曝光、gain、offset 与实测温度属于图像，来自文件头或人工确认，设备关联不覆盖。

## 校准

- 组默认与成员覆盖随集合版本保存；成员缺失键表示继承，显式 null 表示不使用，对象表示覆盖。
- 目标固定为对应用途的 Master 校准素材版本或校准集合版本；不自动匹配、不执行校准、不制作 Master。
- Master Light 属于亮场；校准库与亮场视图独立，未知用途仍可从全部素材访问。
- Light 可选暗场、平场与 Bias，Flat 可选 Bias 与暗平场，Dark 与 Dark-flat 可选 Bias。
- 仅关联变化也发布新集合版本；成员变化与追加保留旧默认与未受影响成员的覆盖。
- 组曝光汇总只累加 subframe 的 `exposure_seconds`，不加入 integration 时间或 Master，并区分已知与未知数量。

## 结果与导出

- 已检查结果归 `src/astrophotoflow/modules/data/results/`；Data 节点读取固定 `APF_SCIENCE` 引用或原生 IMAGE 输入，连接输入优先，冲突明确失败。
- `APF_FILE_REFERENCE` 交接坏点表、ICC、比较星 CSV、WCS 与脚本，不伪装成科学图像。
- 导出默认复制完整容器；显式格式与精度只影响副本，不隐式归一化、裁剪或开发 RAW，预览 JPEG 不是科学输入。

## 回收站与原件保护

- 移除、恢复与永久清理分别操作；永久清理先预检引用影响并返回指纹，用户确认后用同一选择与同一指纹执行。
- revision 或影响变化返回冲突，不自动重试或扩大范围；文件系统与数据库不是统一事务，部分失败保留失败项。
- 校准引用与正在生成的大图参与清理检查；仍被保留组版本引用的目标不能清理。
- 消费者与目标同时选中时先保留目标，目标转为独立可重试记录，不递归重试。

## 对外契约

- HTTP 路由在 `src/astrophotoflow/interfaces/http/data/`（素材、集合、项目、设备、校准、结果、导出与回收站）。
- 契约模型在 `src/astrophotoflow/contracts/`，字段以 [OpenAPI 快照](../api/openapi.json) 为准；查询入口见[参考](../references.md)。
- 公开入口是 `src/astrophotoflow/modules/data/public.py`；其他模块不读本模块私有 ORM。
