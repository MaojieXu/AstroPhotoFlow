# ② 数据与资产管理：前端界面

状态：已有资产、集合、设备资料、导入、预览、校准引用和回收站实现。

职责：资产与集合版本、元数据、设备快照、原件与预览生命周期。

允许依赖：core、contracts；其他模块只通过明确公开入口调用。

`api/` 保存 HTTP 客户端与 Zod 消费模型，`workspace/` 保存现有组件与状态；包外通过包入口使用 Workspace。`App.vue` 保留为既有组件测试入口，不是独立产品应用。

[七模块导航](../../../../../../docs/architecture/module-map.md)记录实际入口、契约和测试。未实现能力先细化对应任务，再新增真实代码；目录存在不代表功能可用。
