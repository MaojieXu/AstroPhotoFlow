## 当前素材库界面

本机导入由LocalImportPicker经授权目录浏览选出当前层明确文件清单，ImportDialog保留可选资料并提交POST imports／managed；不再挂载浏览器上传输入。无目录或目录不可用时经宿主打开原生workbench设置页。受理范围和快照由后端固定，WorkspaceRecords区分登记／原件可用／预览；ImportTasks按report.content／preview展示进度并发出通知，由LibrarySidebarTab映射原生Toast，ImportIssueDialog只在本次通知操作时读取详情并调用既有失败项重试。通知按workspace、taskID及类别持久去重，不在列表显示历史结果横幅。历史关闭按钮／常驻失败说明以下列最新候选为准。


我的设备采用简洁列表：普通行透明、无卡片边框，悬停轻微强调，选中时使用主题背景及侧边色标，保留键盘焦点。右侧编辑操作预留宽度，长名称／副标题省略；名称与型号重复时仅展示类别，独立型号保留。现有勾选、编辑、删除及组合表格流程不变。

我的设备单击行选中后，仅在该行右侧显示“编辑”按钮，点击打开与新建共用的EquipmentFields表单；切换目标时按钮随选中移动，列表下方不再显示编辑按钮。移除双击打开行为及下方重复详情，按钮保留原生键盘操作。编辑预填值、固定类型，取消／保存操作统一提交改动字段，保留revision冲突、失败输入及未保存确认，保存后保留选中。未触碰的隐藏规格及不对称像元值不改，勾选删除保持。

设备组合和我的设备共用精简工具栏：搜索与单个新建操作同排，刷新及批量管理在原生更多菜单；页签和批量复选框复用原生组件。默认隐藏记录选择框和组合选择列，仅批量模式显示全选当前页、数量、删除及完成；零勾选不退出模式，搜索／分页／排序／切换页签清空并退出。类别用Lucide图标，主题语义色表达选中。空状态不显示计数／分页，每页50条不修改素材库偏好，保存及影响预览／删除接口不变。

设备组合使用 `EquipmentSetupTable` 六列表格，展示名称、相机、望远镜、赤道仪、滤镜、光学附件，未配置为 `—`，多件设备摘要悬停查看完整名单；设备管理页签、表格和组合表单移除ⓘ图标。历史成像系统归望远镜列并标明。各列表头驱动组合专用服务端排序，覆盖全部匹配记录后分页；排序回第一页并清空选择，脏草稿及保存期间禁止排序。组合排序与素材库状态独立，表格内部横向滚动；我的设备继续原紧凑列表。

选中组合后并排显示新建拍摄预设及编辑设备组合，下方保留已有预设；编辑直接打开现有组合表单，更多菜单保留刷新和删除组合，不再重复展示组合标题、设备数量及名单。组合可多选滤镜，预设从所属组合注册滤镜中选择一片，未指定沿用首片的既有默认规则。预设表单展示可选名称前缀、滤镜、温度、曝光及ISO／增益，增益模式同时显示Offset；完整名称自动拼接已填写参数后缀，再次编辑拆出前缀。旧分类、相机默认值、累计曝光、Bin、CFA和说明仍随原预设保存，不因隐藏而清除。

素材库的“设备管理”入口默认设备组合，另有我的设备；不再提供项目页面和设备回收站。组合按相机、望远镜、滤镜、赤道仪和配件分区，可就地新建可复用设备，已保存设备不随取消组合删除。设备／组合／预设直接删除先展示实际影响，保留历史快照；“图像组／素材／回收站”是界面统一术语，协议中的dataset／asset／trash不改名。Workspace的可选`controls: LibraryControls`由宿主注入原生FormItem、Button、Input、Dialog、搜索多选／单选器和Textarea，包内LibraryButton／LibraryInput／LibraryTextField仅桥接这些组件；LibraryInfo沿用原生Button tooltip，支持键盘焦点与悬停，长标识完整换行。独立组件测试和App入口保留HTML控件路径，UI包不导入原生源码。设备管理内容区上限640px、列表约48px；设备／组合／预设及删除确认使用原生md弹窗（上限576px、85vh），正文滚动而标题及操作区固定。组合用五行搜索多选，新增和编辑组合内设备在同一弹窗切换；输入及普通按钮32px，设备编辑随表单保存提交，组合和预设继续整组保存。

简约视图只显示预览、名称及关键状态、分类和曝光，完整参数仍在细节视图。所选单图可直接检查文件变化；对象切换清除旧观察，迟到结果不写入其他素材详情。项目添加图像组与已选固定组都使用图像组资料编辑，PATCH保留dataset的revision边界。observed_mtime_ns保留非负数值传输，当前UI不消费其精确纳秒值，不以JS安全整数上限拒绝正常响应。

素材库顶部只保留导入、设备管理和原生更多菜单，分类／搜索／筛选直接可见；更多提供刷新、批量管理、回收站及显示方式／每页数量单选组。批量模式显示数量、删除和完成；单页隐藏翻页，每页数量移出底部。表头复用文字按钮并保留排序。导入活动进度按原件字节显示，成功与异常由右上角一次性Toast表达，素材行异常仍可查看，不新增导入历史页。

预设空分类显示“未设置”，ISO／Gain按所选模式显示，切换不清除草稿或改变保存优先级。说明与UUID移入ⓘ，错误、未保存、固定版本和实际作用成员数保持可见。候选及实际验证见[验证矩阵](../../../../../../docs/development/test-matrix.md#m2-ui-optimization)。
