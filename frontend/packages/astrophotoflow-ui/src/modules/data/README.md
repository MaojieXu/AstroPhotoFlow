# ② 数据与资产管理：前端分工

[②唯一概要设计](../../../../../../src/astrophotoflow/modules/data/README.md)维护完整场景、十二类能力、权威状态、交接和验收；本文只补充UI职责，不另存一套业务规则。概要完成不表示所选结果保存、完整比较或本地记忆已经实现。

`api/` 保存 HTTP 客户端与 Zod 消费模型，`workspace/` 保存组件、表单草稿、筛选、分页和选择状态；包外通过 Workspace 公开导出消费。`App.vue` 保留为既有组件测试入口，不是独立产品应用。沿用原生 Vue／Pinia和侧栏，UI不反向导入原生 Store、画布单例或直接访问业务数据库。B21精简设备录入并映射单一相机像元尺寸到历史x／y字段；B23通过“检查变化 → 用户确认”两步接纳同一素材身份下的新内容版本，不自动修改工作流引用。

## 场景补充

按[导入及画布场景](../../../../../../docs/requirements/README.md#scenario-import)呈现按钮单个／批量与Agent分批导入的真实分项状态、构成疑义及选定范围；素材库拖入单个／集合交④⑤建立固定科学引用。原始视频登记、原件可用与静态首帧预览分别表达，不以预览就绪推断整段视频可处理，不新增帧资产界面。

| 范围 | 已有界面及待补目标 |
|---|---|
| 导入与资料 | 已有文件／文件夹上传、传输进度、导入阶段状态、参数与设备／组合／预设、未保存保护。网页文件夹仅选第一层支持文件，不能描述为授权根目录递归入口 |
| 集合、项目与校准 | 已有固定版本引用、完整组成员、筛选匹配数、历史查看、默认／继承／不使用／覆盖和回收站。当前资料与固定版本分别显示，不把当前名称或设备信息回写历史 |
| 预览 | 已有100 px缩略图、1080 px大图、单图自动拉伸、轮询和显式重试。关闭释放轮询／URL，迟到响应不重开；完整缩放平移、比较／ROI及指标仍待实现 |
| 项目结果与全局库 | 待实现：用户选择完整结果保存到素材库，可命名或使用默认名，不按中间／最终分类限制；不要求素材详情展示处理步骤及来源。完整中间文件不作为长期保存内容，画布可保存多次压缩预览 |
| 记忆及项目汇总 | 待实现：偏好／背景／经验／摘要及候选、修订、停用删除和作用域；汇总消费②⑤公开事实，不在浏览器保存第二份资产、工作流或运行权威 |

HTTP服务负责认证、revision、范围、引用保护和登记；UI只报告实际接收的状态。原生挂载和画布协调位于宿主桥接，领域状态复用方向沿①概要及既有ADR验证，画布确认归⑤。本次取舍见[结果与预览ADR](../../../../../docs/adr/WORKBENCH-DATA-0055-selected-results-and-previews.md)。

已有测试位于[数据UI测试](../../../tests/modules/data)，包含API契约、导入、组、设备、校准、预览和回收站；新增B23确认交互及B21精简设备表单测试已补入。所选结果由⑤提供运行选择界面，完整比较及记忆仍未实现。验证记录以开发矩阵中M2候选为准。
