# 数据与资产界面

提供素材与集合、项目、设备、导入、预览、结果与回收站的业务界面与查询；对外入口由包 `src/index.ts` 决定。

## 结构

`api/` 放客户端与 Zod 消费模型，`workspace/` 放素材、固定组、设备与预设、校准、项目与回收站界面，`imports/`、`media/`、`results/` 分别承接导入、查看与结果；`App.vue` 只是组件测试入口，不是第二套产品应用。

## 不变量

表单草稿、分页、筛选与勾选归 UI；revision、固定成员、来源与删除影响由服务返回，删除保留历史快照。预览与查看状态不是科学输入；本机选择器只返回文件与当前层文件夹，确认后才托管导入。素材简约列表点击名称选择原生落点、整行可拖入，缩略图经宿主注入的查看器打开，本模块不导入原生组件。

## 测试

包内 `tests/modules/data/`（根 `pnpm test`）。素材库行为见[素材库子系统](../../../../../../docs/subsystems/library.md)。
