# ⑤工作流、执行与 Agent 交互：前端分工

⑤统一负责工作流、执行与Agent交互。唯一概要见[⑤概要](../../../../../../src/astrophotoflow/modules/workflows/README.md)，必要数据见[⑤数据设计](../../../../../../docs/architecture/data-models/05-workflows.md)。本目录仍仅文档，没有新增组件、公开导出或画布MCP实现。

## 界面与原生复用

- 复用原生画布、节点控件、页签、JSON加载、文件保存／另存、撤销、图转换、队列、进度和取消，不另建编辑器或任务系统。
- 展示项目图及实际保存状态。自动保存当前图，原生浏览器草稿表达未同步内容；重要方案另存独立图，重开不承诺永久逐编辑撤销，不建服务端恢复草稿。
- 日常Agent使用局部原生操作，整图JSON用于导入或明确替换；原生运行准备／转换各一次后核对当前内容，再保存一次成功才提交。异步期间人工变化明确阻塞，不重复控件求值或保存另一份图。
- 展示本次实际图、输入、参数、实现、状态错误和日志；④最近测试使用同一运行链接，修改后注明旧内容。保存、实际显示、执行和用户所选完整结果保存分别确认，不设永久回执历史。
- 本次实际执行完成的每个图像节点自动产生压缩预览，经原生UI输出／事件展示；保留多次完成预览并关联运行／节点／输出，不保存实时进度每帧。科学输出独立，不强迫增加Preview节点，不扩大执行范围。
- 用户在目标网页点击“交给Agent”绑定该页面当前图，Agent仅操作此明确且当前显示的画布，不自动跟随另一页面。切A到B后暂停对A后续编辑和新运行，已有处理继续；按原生任务编号将完成预览归A，不改B或抢回视图。无网页对工作流仍可查状态，不支持新编辑／新提交；②导入、③安装等非画布操作按所属规则提供。
- 手动改图含参数、布局、撤销即接管；查看、平移缩放及切页签不接管。用户明确交回后才能继续，读取／重连不恢复已撤销控制，离线接管未确认如实显示。
- Skill已知能力直达，需要发现才混合Top10及定义按需读取，embedding失败明确关键词降级；不新增无具体字段的协作Settings对象或Judge界面。

## 宿主与业务边界

自研界面统一进入本模块并通过包公开导出消费。原生Store、画布、ChangeTracker、graphToPrompt、任务事件与实际应用结果由[宿主桥接](../../../../../src/platform/astrophotoflow)协调，UI包不反向导入原生实现。MCP协议仍在接入层，操作共用HTTP应用能力；项目关联、控制、运行记录和多次预览由⑤保存。

②固定素材和元数据通过公开能力读取，③提供软件就绪及调用观察，④提供定义和更新前后内容；确认更新后参数全用新默认，未变端口保线、变化端口断线。用户选择的完整结果交②保存；删除工作流清理专属预览，不删已保存素材。

## 阶段与验证

S2入口与检索，S3项目编排／自动保存／另存／可选测试，S4真实处理与自动预览，S5活动画布、切换、接管及接续，S6复杂节点与完整场景。新桥接、逐节点预览、持久历史和精简MCP均待实现或验证；现有原生／数据测试不代替新验收。

核对重开图、另存、多轮预览、缺依赖、切图迟到写拒绝与后台预览归属、取消实际停止、节点更新、结果保存及真实客户端。源码和既有测试见[概要验证入口](../../../../../../src/astrophotoflow/modules/workflows/README.md#verification)，取舍见[工作流ADR](../../../../../docs/adr/WORKBENCH-WORKFLOWS-0058-native-workflow-execution-and-agent-interaction.md)。本轮仅文档检查，不执行构建或业务回归。

本轮三项选择及替代方案见[ADR-0059](../../../../../docs/adr/WORKBENCH-WORKFLOWS-0059-native-editing-save-and-agent-target.md)，具体输入输出及桥接验证见[⑤接口契约](../../../../../../docs/api/platform-contracts.md#workflows)。

第④阶段的存储／原生接入取舍见[ADR-0060](../../../../../docs/adr/WORKBENCH-CONTRACTS-0060-minimal-storage-and-native-bridge.md)，公开TS入口、Python组合与测试文件见[详细设计](../../../../../../docs/api/platform-contracts.md#workflows-design)；本目录仍无新增实现。

新图先选项目、完成原生保存和实际文件关联，再交给Agent；临时草稿只用原生机制。图控制允许状态跨客户端共享，已撤销状态不因新客户端或重连恢复，不新增客户端身份/权限面板。
