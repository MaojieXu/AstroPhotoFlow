# ④ 节点构建与发布 开发边界

- 先读本目录 README 与[模块导航](../../../../../../docs/architecture/module-map.md)，再读取任务涉及的契约。
- 节点制作、常用／高级参数、最近测试与旧内容提示、更新影响确认；⑤更新参数及变化端口连线，不设强制测试发布或旧版选择。业务权威以Python④概要为准。
- 消费core、contracts及公开应用能力；宿主通过包导出接入，原生注册、子图与画布协调归桥接区，不反向导入原生Store或画布。
- 当前状态：概要分工已成文，两侧仍仅文档，没有节点组件、公开操作或热发布实现；导出安装仅为后续待规划目标。
- 仅修改任务所属模块；跨模块使用公开入口，不直接引用其 ORM、私有函数或前端内部 Store。
- 不创建假接口、空服务类或预注册能力；新实现必须更新真实状态与验收记录。
- 验证入口：本模块尚无独立实现与测试；首次实现必须补充明确的验证入口。
