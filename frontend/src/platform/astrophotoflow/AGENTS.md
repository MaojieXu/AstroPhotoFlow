# 原生平台集成约束

- 本目录负责产品界面与原生应用集成，可直接使用原生 Store、画布、侧栏与生命周期；业务 UI 只经 `@astrophotoflow/ui` 公开入口引入，不引用 `packages/astrophotoflow-ui/src` 内部文件。
- 不复制资产业务、不直接写数据库、不建立第二份工作流权威状态；图写入使用当前工作流接口与原生支持机制，提交前核对明确目标与内容。
- 保留常驻画布、侧栏顺序、视口、未保存编辑保护与真实回执，不用本地假数据替代服务响应。
- 内容变化使旧画布请求失效；查看、缩放不改变内容标记；切图暂停后续写与提交；迟到结果不抢当前视图。
- 测试与类型检查在仓库根运行：`pnpm test`、`pnpm typecheck`。
