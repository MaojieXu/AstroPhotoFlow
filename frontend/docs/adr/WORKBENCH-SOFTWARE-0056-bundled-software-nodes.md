# ADR-WORKBENCH-SOFTWARE-0056: 软件包与配套节点

Date: 2026-10-27

## Status

Accepted

## Context

用户希望从列表安装项目准备的固定软件副本及节点，使用平台统一 MCP，并简化旧版本并存的管理。

## Decision

网页及 Agent 安装软件包后发现配套节点。缺少登录或许可时显示原因，用户自行输入敏感信息。更新前展示工作流与参数影响并由用户确认，运行结束后替换软件及配套节点，变化参数采用新默认值；移除或缺失的节点保留提示。历史运行事实保留，不承诺旧软件长期可用。

用户自制节点的更新规则由④维护。软件发行方式与内部通信留待实际适配。
