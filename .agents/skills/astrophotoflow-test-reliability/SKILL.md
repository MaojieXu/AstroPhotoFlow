# 测试可靠性

## 触发

新增或修改涉及回环端口、临时目录、后台线程或进程、workspace 状态、浏览器与异步 teardown 的测试时；排查 flake 时。

## 执行拓扑

- pytest 可能与同机其他进程并发；并行时用 `--basetemp=.artifacts/pytest-<task>` 分临时目录。
- CI 在 Ubuntu 与 Windows 上运行同一套 Python 测试，两个常驻服务共用回环端口。
- 浏览器测试 worker 为 1、失败不自动重试；报告用 `APF_BROWSER_REPORT` 分配独立子目录。
- 进程隔离不隔离主机端口、固定路径、外部服务与继承的子进程。

## 资源分配

- 端口绑定 0 后读取实际地址，不先扫描空闲端口再延迟绑定。
- 临时根用 `tmp_path` 或 `--basetemp`；每个测试独立 workspace、数据库、缓存与输出目录。
- 共享数据库、socket、锁与输出位置加唯一命名；必须独占的路径用独占创建。
- 记录用的稳定标识与临时传输地址分开，在 fixture 内转换。

## 平台语义

- Windows 环境变量名大小写不敏感，不把 `http_proxy` 与 `HTTP_PROXY` 当两个键。
- Windows 文件句柄异步释放：重命名或删除按观察到的竞争做有界重试，对齐软件安装状态原子替换的 retry 上限。
- NTFS 时间戳精度不同；断言依赖回读值，不用写入前的记忆值。
- 依赖 POSIX 权限或信号的用例显式 skip 并写明原因，不弱化全平台断言。

## 同步与超时

- 等健康检查、就绪事件、状态转换或已拥有的 promise，不用固定 sleep。
- 超时只作等待上界，不让超时决定断言成立。
- 竞态用屏障或延迟 promise 把重叠放到确定点；不依赖调度顺序。
- 时间本身是被测对象时注入或伪造时钟，并恢复真实时钟。

## 清理到静止

- 获取资源后立即登记清理，断言失败也能释放。
- 清理顺序：停止新回调与请求 → detach 监听 → 终止自有工作 → 等待子进程退出或 server close。
- 只调用 `close()`/`kill()` 不等完成信号不算清理完成。

## 证明回归

- 修复前先观察到目标回归；新增静态守卫时临时引入被拒用例并观察失败。
- 端口、子进程与共享路径的修复用独立进程并发运行验证。
- 观测外部状态、事件、文件、退出码与清理结果，不信组件自报。

## 拒绝掩盖

- 不做无依据的超时上调、重试、全串行、吞异常、弱化断言或清空前 sleep。
- 例外只留给已记录的外部服务边界；重试不等于修复。

## flake 诊断

- 固定证据：命令、退出码、日志与 `.artifacts/reports` 产物。
- 分类：资源分配、时钟、平台语义、teardown、外部依赖。
- 最小复现后按 owner 修；诊断请求保持只读，先报告原因与证据。
