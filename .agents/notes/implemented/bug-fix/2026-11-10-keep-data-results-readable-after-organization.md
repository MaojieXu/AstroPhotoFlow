# Agent Note: 目录整理后保留 Data 结果的文件入口

Status: Implemented

## Problem

可读目录整理会改变托管原件位置。Data 节点直接交接素材时，已检查结果原先沿用原件路径，完成后的整理会使结果路径失效。相关目录策略见[可读素材目录记录](../feature/2026-11-10-readable-library-and-calibration-state.md)。

## Decision

Data 执行在自身目录保留文件入口，源素材的稳定 ID、参数、校准及原始输入路径仍保存为当次来源事实。支持硬链接时共用文件内容，其他文件系统使用已有复制与散列能力。结果检查继续核对登记哈希，时间戳变化触发完整校验，恢复原字节后可重新读取。

## Alternatives considered

整理时改写过去的调用记录会混入当前资料。结果读取时重新查询当前素材位置需要把数据库依赖扩展到全部结果读取入口。强制复制每份托管原件会增加常见文件系统上的处理与存储成本。

## Consequences

原件位置改变后，已完成 Data 结果保留执行自有入口。执行文件随原生运行产物管理，清理素材目录中的文件入口与清理执行产物分别计数。已登记内容的变化继续使校验失败，新的字节内容通过重新导入获得素材身份。
