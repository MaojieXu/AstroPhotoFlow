# Agent Note: 统一 Windows 并发导入路径表示

Status: Implemented

## Problem

并发导入创建暂存目录时，Windows 有时把同一个绝对路径解析为带扩展前缀的路径。与普通数据目录做比较时，合法暂存文件会被误判为越界。

## Decision

仅当解析结果与预期绝对路径的扩展表示完全相等时，使用预期路径执行原有边界与链接检查。

## Alternatives considered

重试解析依赖目录创建的时序。无条件去除扩展前缀会扩大接受的路径表示。逐字匹配只覆盖实际复现的等价路径。

## Consequences

并发导入可以使用同一个任务暂存目录。路径检查继续验证归属并拒绝解析到其他目录的路径。
