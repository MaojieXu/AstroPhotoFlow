# Agent Note: 恢复素材预览地址与当前源文件读取

Status: Implemented

## Problem

素材节点显示“服务错误响应不符合接口契约”。共享 view_base 只返回素材路径，前端追加 viewer 后请求落到原生服务的未注册地址。媒体源查询已改为返回素材与路径，参考拉伸和图片读取仍解包三项，导致生成或交付失败。

## Decision

共享媒体地址恢复同源代理前缀与 previews 后缀，覆盖素材和项目引用。参考拉伸及读取租约按当前两项返回值解包。复用现有媒体客户端、缓存与回归测试。

## Alternatives considered

在每个前端消费方补地址会重复协议适配。共享地址函数已有画布、素材库、数据集及项目调用者，统一修复该入口保持现有客户端契约。

## Consequences

开发工作台重启后，真实 FITS 素材预览为 available，尺寸 3294 × 1990，概览图与瓦片均返回 HTTP 200。浏览器节点已显示图像。相关测试 37 项通过、5 项失败，剩余失败涉及测试缩略图数据缺失。全套 pytest 使用 maxfail=1，55 项通过后停于现有错误本地化键覆盖失败。本次修改限于共享地址与两处解包。
