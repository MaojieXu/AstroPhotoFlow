# Agent Note: 统一预览显示控件与节点比例

Status: Implemented

## Problem

节点预览使用原生下拉框，与宿主控件的尺寸和弹层样式存在差异。“默认显示”没有解释当前应用的 RGB 处理，固定高度的预览框也不能随节点宽度保持图像比例。

## Decision

PreviewControls 复用紧凑版 SingleSelect，保留原尺寸与自动模式的 null 参数。自动模式显示为“自动选择”，根据已有预览响应中的通道与白平衡增益展示当前处理结果。数据输入和数据运行节点按图像宽高比设置预览区域，高度限制为 160–480 px，未知尺寸使用 4:3。

## Alternatives considered

原生 select 可以继续表达互斥选择，但共享 SingleSelect 已提供统一焦点和弹层。显示结果使用服务现有通道与配方信息，缺少这些信息时仅呈现自动选择。

## Consequences

前端请求继续使用原有参数与接口。控件交互及自动模式说明测试通过，查看器、数据输入和数据运行节点相关测试共 32 项通过，宿主类型检查通过。
