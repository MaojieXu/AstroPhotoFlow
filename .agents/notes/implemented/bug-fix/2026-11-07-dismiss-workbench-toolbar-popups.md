# Agent Note: 统一工作台工具栏浮层的关闭与焦点

Status: Implemented

## Problem

设备类别和更多菜单由原生控件挂载到页面顶层。侧栏拦截了文档冒泡阶段用于检测外部点击的事件，旧菜单可能盖住新建或编辑表单。素材导入、素材筛选和项目筛选各自保存展开状态，部分切页入口留下旧浮层。

## Decision

工作区用一个状态管理导入、素材筛选、项目筛选、设备类别及两处更多菜单。捕获阶段处理侧栏内的外部点击，切页、断线和打开表单时清理展开状态。工具栏的原生菜单和设备类别下拉允许下一次点击直接到达其他控件。交接时抑制旧浮层的自动回焦，按 Escape 收起时将焦点还给当前触发按钮。 [工作区浮层状态](../../../../frontend/packages/astrophotoflow-ui/src/modules/data/workspace/WorkspacePage.vue)

## Alternatives considered

全局放开侧栏的事件冒泡会把交互传给画布。调低旧菜单的层级只能改变遮挡，返回页面时仍可能恢复旧状态。保留各菜单独立展开，需要在多个入口重复处理关闭和焦点。

## Consequences

在独立浏览器预览中复查了设备类别和更多菜单打开表单、素材库切分类、项目筛选打开新建表单，以及键盘切换和切栏返回。组合表单内的滤镜下拉仍可操作。导入确认和断线场景只核对了源码。浏览器回归用例已补充，本轮验证为手动预览。 [浏览器回归用例](../../../../tests/browser/native-web.spec.ts)
