# Agent Note: 统一 Bundle 与自定义节点双语显示

Status: Implemented

## Problem

Siril 开发 Bundle 的节点接口已经返回中文，但运行网页中的旧严格校验器不认识后端新增的 calibration_effect，整个目录响应被拒绝，翻译注册未执行。自定义节点目录主动返回空显示资料，无法沿用 Bundle 标签。既有实例缓存参数和端口标签，旧默认译名还可能被原生创建流程写成实例标题。

## Decision

保留严格响应校验，按当前契约生成 SDK 与网页。节点定义以可选中英文覆盖保存显示资料，由 nodes 按执行绑定组装统一的 NodeCapability.display。自定义名称、说明与分类缺省保留自身文字，端口和参数继承一致的操作标签，固定参数不生成控件标签。覆盖保留省略与空说明的区别，拒绝 null；空覆盖映射不改变旧内容令牌。

前端沿用宿主 Vue I18n 与目录事件，替换译文并清理失效词条。参数、端口及默认标题在显示时解析当前译文，已有实例刷新时同时识别上一版默认名称，保留用户自定义标题。语言切换在原生重载前通过当前工作流的 captureCanvasState 保存实际画布，继续使用原生撤销、草稿与刷新流程。目录查询失败保留已有能力与翻译，并显示错误。

## Alternatives considered

把译文集中写入平台静态词典会让独立 Bundle 和外部 Agent 创建的节点依赖平台发布。按开发与安装目录分别编写桥接会重复同一显示规则。放宽响应校验会掩盖前后端版本不一致。直接把译名写回端口和参数状态会把显示变化带入可编辑图内容。

## Consequences

开发和安装来源共用软件翻译读取入口，自定义节点共用能力目录与前端显示链路。输入及参数绑定从操作指向节点，输出绑定从节点指向操作，显示组装遵循各自方向。新增契约字段需要同步生成物并更新 workspace 网页，旧构建会继续明确报告版本漂移。验证使用独立工作台，完整测试中的数据模块与旧接口夹具失败另行保留日志。
