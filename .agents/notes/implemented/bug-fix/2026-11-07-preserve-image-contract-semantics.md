# Agent Note: 保留图像入口的契约语义

Status: Implemented

## Problem

生成 CLI 过滤了必填的 `null`，导致首次单图校准绑定无法提交。显式 FITS 导入只规范化带偏移的时间，合并的检查摘要也可能组合来自不同 HDU 的日期与时标。图片搜索在分页后逐项读取元数据和版本。

## Decision

CLI 生成器从离线工具契约推导必填可空字段，并校验 FastMCP 参数过滤模板。FITS 显式导入从检查快照选择日期及适用时标，确定的 UTC 写入原有字段，日期原文继续保留。图片搜索按页加载元数据和当前版本，与详情共用映射和归属检查。

## Alternatives considered

直接改生成文件会在重新生成时丢失修复。采用合并后的 FITS 摘要会让其他 HDU 的时标影响所选日期。改写分页联接会扩大读取路径的改动范围。

## Consequences

首个校准绑定可通过生成的 CLI 传递显式 `null`。缺少 HDU 快照的既有检查清单仍可按已知偏移转换。已受理任务继续使用冻结的资料。图片搜索的详情读取次数随页数增长，每页至多执行两条详情批量查询。
