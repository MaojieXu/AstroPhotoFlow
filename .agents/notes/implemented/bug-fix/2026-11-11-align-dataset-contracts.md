# Agent Note: 保持数据集摘要与校准契约一致

Status: Implemented

## Problem

素材库打开数据集列表时，前端把列表摘要交给完整数据集校验，导致渲染失败。成员更新把 Pydantic 校准模型直接交给使用 JSON 字典的校准逻辑。校准列表也收到了仅详情接口声明的回收站字段。

## Decision

前端按现有摘要字段识别列表记录，并在项目选择入口沿用完整数据集校验。成员更新在 DTO 边界序列化校准映射，保留省略和空对象的含义。校准列表使用原有列表契约，详情中的回收站状态随目标批量读取。

## Alternatives considered

曾考虑放宽两类记录的校验或统一列表与详情响应。已有独立契约足以表达各自字段，调整交接处即可消除混用。

## Consequences

列表仍能严格校验响应。成员更新可以提交当前 Master 目标。校准目标的回收站状态不会随列表项逐条查询。
