# Agent Note: 按素材库接口限定响应与清理范围

Status: Implemented

## Problem

FITS HDU 列表把原始头部卡片传给严格的列表模型。回收站从已移除数据集选择单个子项时，也会把这条父组成员关系列为外部引用。

## Decision

HDU 列表只投影其响应模型声明的列。永久清理预检依据已验证的子项来源区分当前父组成员关系与外部引用，并将范围内的成员关系写入指纹供执行时复核。

## Alternatives considered

扩大列表响应会重复头部卡片接口。按任意已移除数据集豁免成员引用会扩大用户选择。两处都可以在现有边界内修复。

## Consequences

HDU 列表可保留严格校验。选中子项仍需同一预检指纹，未选择的项目、数据集和校准引用继续阻止永久清理。
