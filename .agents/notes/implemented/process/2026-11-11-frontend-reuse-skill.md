# Agent Note: 前端复用与架构导航技能

Status: Implemented

## Problem

前端任务需要反复定位 ComfyUI 原生组件、自研业务包装、宿主控件注入和页面装配。只找到底层组件容易遗漏已有业务适配与依赖方向。

## Decision

创建仓库级 astrophotoflow-frontend 技能，并从根约定提示前端任务加载。入口按任务路由到架构导航与组件路由，保存已核实的源码入口、代表调用者及验证配置。架构与行为契约链接现有权威文档，组件字段以当前代码为准。

## Alternatives considered

全量文件清单难以表达复用关系，维护成本高。只保留搜索步骤会重复发现相同入口。全局个人技能难以随仓库改动同步维护。

## Consequences

前端任务可从问题类型直接进入相关源码与调用实例。新增或移动已收录入口时需同步对应导航项；修改接口前仍需核对当前源码。索引按需加载，项目既有边界与验证规则继续由原文维护。
