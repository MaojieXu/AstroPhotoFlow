# Agent Note: 素材库与项目流程实施交付记录

Status: Implemented

## Problem

本次聊天先核对素材库、项目、数据集、校准及回收站的实际实现，再按用户确认的规则完成修正。记录保存聊天归档时的实现、产物、验证与部署状态。此前的实现取舍见[素材引用与导入边界记录](../bug-fix/2026-11-10-library-reference-and-import-boundaries.md)。

## Decision

- 每次独立导入登记独立素材 ID 和托管原件。成员表对 asset_id 设置全局唯一约束，同一素材最多属于一个数据集。移除成员保留原件，解除归属后允许重新归组。
- 永久清理检查所选范围外的项目、数据集、校准和来源引用，并返回阻断对象。通过现有任务准入与软件调用、导出共用保护，覆盖输入准备阶段、实际输入和辅助输入。取消准备操作会等待后台读取停止后释放保护。
- 项目引用、数据集成员、校准目标与人工来源声明统一检查回收站和有效状态。分类修改在事务内检查受影响的消费者与槽位，关系失效时回滚。
- 设备删除保留原始导入快照，对同一操作涉及的每份素材推进一次 revision，并持久化更新时间。
- 导入显式选择独立素材、新建子帧数据集或追加已有数据集。受理时记录目标项目及 revision，关联结果保存到原任务。失败后可使用已成功登记的素材修复分组或重新关联项目，未知结果按原请求 ID 查询。
- 组内最高与最低实测温差不超过 1°C 时匹配，包含边界。超出范围及其他拍摄参数差异返回 warning，保留真实数值。数据集详情和 dataset.json 展示差异与未知数量，详情同时展示引用项目。
- 后端、HTTP、Python 客户端、CLI、MCP、前端和原生桥接已完成对应适配。数据库基线、OpenAPI、SDK、CLI 与 118 个 MCP 工具清单已重新生成，中英文文档和 Plan.md 已同步。
- 本轮工作位于 codex/node-localizations 分支，在已有大量未提交改动上局部修改。交付记录保存在[交付回执](../../../../.artifacts/build/library-flow/delivery.json)，生产构建输出见[构建日志](../../../../.artifacts/build/library-flow/frontend-build.log)。

## Alternatives considered

用户确认独立导入与单一数据集归属，取消跨数据集共用原件的设计前提。文件数量自动创建数据集的行为改为显式导入方式。温度精确相等及拍摄参数差异拒绝保存的行为改为参数诊断与 warning。导入修复复用已有任务和操作回执。

## Consequences

交付时 Python 编译检查、src 与真实素材测试源码的 Ruff F/E9、新模块完整 Ruff、文档门禁、自研 UI 与原生前端类型检查、前端依赖边界及生产构建通过。依赖边界检查覆盖 303 个模块与 1310 条依赖，生产构建退出码为 0。Windows 沙箱中的 CLI 生成曾卡在 asyncio socketpair 初始化，宿主机离线生成成功完成。

真实素材回归源码已更新，并新增 test_library_relations.py 的 8 个测试函数，覆盖独立重复导入、外部引用清理保护、回收站关系、分类回滚、活动软件占用、设备 revision 与请求幂等性。按用户要求，pytest、前端行为测试、浏览器及端到端验收、批量导入复现和真实软件处理均未执行。

本轮交付更新了源码、数据库基线与仓库构建产物。现有 dev 数据库未重建，前端构建未安装至 dev，本轮未执行服务启停。现有 dev 使用这些改动依赖新基线初始化及前端产物安装。旧数据迁移未实施。构建日志保留 SVG 样式移除和插件耗时提示。
