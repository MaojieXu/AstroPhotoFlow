# Agent Note: 子帧数据集共用一套校准

Status: Implemented

## Problem

数据集允许混入主帧，成员覆盖让同组的有效校准随成员变化。项目界面没有把子帧数据集与独立主帧区分开。

## Decision

数据集只接受固定子帧版本。每个数据集版本按用途保存一个校准选择，主帧以独立固定素材引用进入项目。网页、HTTP、MCP 与生成 CLI 使用同一规则。数据库从新的单一基线初始化。

## Alternatives considered

保留成员覆盖需要同时维护组级和单帧校准规则。迁移开发数据需要为混合成员与冲突的旧绑定定义拆分规则。当前开发阶段采用空工作台验证新结构。

## Consequences

需要不同校准的子帧分别成组。修改校准发布新固定版本，项目引用按明确选择切换。已有旧结构的数据库由初始化入口拒绝。
