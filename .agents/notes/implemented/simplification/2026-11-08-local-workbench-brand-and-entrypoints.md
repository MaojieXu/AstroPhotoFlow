# Agent Note: 本地工作台使用独立品牌和入口

Status: Implemented

## Problem

本地工作台的启动、账户、模板与帮助入口带有上游产品标识。公共目录还将本地功能用不到的宣传素材带入发行物。

## Decision

将[菜单标志](../feature/2026-11-08-brand-local-workbench-menu.md)复用于启动、标签与安装。以发行类型控制菜单与命令可用性，本地节点目录展示实际注册节点。用显式清单选择本地发行的公共素材并保留许可信息。

## Alternatives considered

清理上游模块源码会扩大合并与兼容影响。只改菜单文案无法覆盖快捷键和启动资源，因此在本地入口与发行边界处理。

## Consequences

上游源码与内部 ID 保留，旧工作流继续走现有加载路径。新增本地公共素材时需将其加入构建清单。
