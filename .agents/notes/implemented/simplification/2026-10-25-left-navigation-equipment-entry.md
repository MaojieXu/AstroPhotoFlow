# Agent Note: 左侧导航与导入旁的设备入口

Status: Implemented

## Problem

素材工作区导航和常用设备操作的位置需要与实际使用路径对齐。

## Decision

把导航放到左侧，把设备入口放到导入附近。

## Alternatives considered

现存材料未记载该项决定曾比较的其他方案。

## Consequences

主要工作区路径集中，设备操作可从导入上下文进入。
