# Agent Note: 分组回收站与永久删除

Status: Implemented

## Problem

素材清理需要区分移入回收站、恢复和永久删除。

## Decision

增加分组回收站及永久删除操作。

## Alternatives considered

现存材料未记载该项决定曾比较的其他方案。

## Consequences

删除具有清晰的生命周期，恢复问题随后单独修复。
