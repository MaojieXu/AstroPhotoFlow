# Agent Note: 将赤道仪纳入器材资料与快照

Status: Implemented

## Problem

实际器材组合需要记录赤道仪身份。

## Decision

增加赤道仪登记、修改、可选组合成员及明确选择后的素材快照。

## Alternatives considered

现存材料未记载该项决定曾比较的其他方案。

## Consequences

赤道仪作为资料记录，不新增硬件控制，也不参与校准匹配。
