# Agent Note: 工作台启动时显示网页地址

Status: Implemented

## Problem

手动启动后要从结构化回执中查找前端地址。工作台复用已有实例或首选端口被占用时，必须使用实际运行地址。

## Decision

`apf start` 成功后在交互式终端的标准错误流显示就绪回执中的网页地址。显式传入 `--open` 时将该地址交给默认浏览器。浏览器启动失败时提示手动访问，并保留工作台的启动结果。

## Alternatives considered

将人类可读提示作为默认标准输出需要现有 JSON 调用方迁移。每次启动都打开浏览器会给自动化引入额外副作用。

## Consequences

标准输出继续提供原有 JSON 回执。复用实例和更换端口都使用运行控制层确认的地址。
