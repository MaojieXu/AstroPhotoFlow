# Agent Note: 可读素材目录与当前校准状态

Status: Implemented

## Problem

稳定素材身份需要同时支持可读的本机目录、多个数据集共用原件和科学处理追踪。文件移动与 SQLite 提交分属两个系统，关系说明写入失败也可能发生在资料保存成功之后。

## Decision

素材采用三种当前校准状态，用户声明与实际软件处理依据分别保存。子帧数据集由用户或 Agent 提交有序成员，按拍摄条件校验一致性。SQLite 保存当前关系，数据集目录内原子发布 `dataset.json` 镜像。目录分配保留文件名、拍摄参数和短 ID，资料修改后的物理位置通过显式整理更新。

整理复用既有请求回执表，先检查完整范围，再逐文件建立新入口并提交实际位置，随后清理旧入口。支持硬链接时复用同一文件内容，文件系统不支持时使用已有复制、BLAKE3 和暂存归位能力。中断恢复核对已登记路径与内容身份，部分结果可按请求 ID 查询。

一次软件调用的素材输入在同一 SQLite 读取事务中取得当前成员、资料与校准，之后固定该次输入。注册设备按稳定 ID 比较，未知设备按文件观察名比较，光学附件和有效焦距参与分组，备注与显示名称修改保留在设备快照中。

## Alternatives considered

逐个端口独立读取可能混合编辑前后的资料。仅先移动再提交会使失败时的登记位置失效。把 JSON 作为可编辑关系权威会引入第二套校验与冲突处理。复制所有整理文件会增加支持硬链接文件系统上的磁盘开销。

## Consequences

镜像失败保留已提交资料，并可重新生成。整理失败保留真实的逐文件位置，复制路径需要临时可用空间。新增真实素材 pytest 源码使用显式分组清单，外部原始素材只读，故障仅作用于临时副本。自动测试、真实软件处理与端到端执行按本次授权保留为后续验收活动。
