# Agent Note: 从检出目录联调 Bundle

Status: Implemented

## Problem

源码要逐包绑定，目录和运行时各自可能滞后。已有画布实例也无法指出自己使用的是旧参数或端口定义。

## Decision

在指定 workspace 的源码绑定中启用仓库根目录的 `bundles/`。软件和原生加载使用同一批绑定，监听句柄放在父目录。前台按实例构造时的原生定义判断是否过期，并沿用节点注册与执行入口。

## Alternatives considered

逐包手动绑定适合仓库外源码。自动改写旧节点需要决定如何迁移参数与连线，用户选择从目录重新添加新版。

## Consequences

目录增删和文件保存能触发同一条刷新链路。定义过期的旧实例仍可在画布上查看和删除。生成器按声明输入运行，普通适配器改动使用源码指纹。
