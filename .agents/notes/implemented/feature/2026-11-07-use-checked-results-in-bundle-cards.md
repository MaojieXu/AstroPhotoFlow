# Agent Note: Bundle 节点共用已检查结果与查看器

Status: Implemented

## Problem

Bundle 节点同时有样本运算组件和完整结果组件。不同类型的结果还需要统一关联媒体成员、分析和空间参数。

## Decision

节点卡片读取已检查的运行产物，缩略图和瓦片共用原生媒体查看器。Bundle 通过公开契约声明产物角色、分析口径和空间编辑参数，节点与 MCP 读取同一批结果事实。

## Alternatives considered

独立样本组件可以缩短部分运算的等待时间，也会引入另一组参数快照和图像来源。按软件分别写卡片可以表达专用布局，代价是每个 Bundle 都要维护宿主组件。

## Consequences

可自动执行的节点仍经原生队列处理完整输入。显示尺寸和通道属于查看状态。空间选区随输入成员和像素位置保存，同一上游操作重跑时以输入、参数和已检查的像素布局核对点位。已有 Bundle 可以使用基础结果展示，补充类型声明后可以显示关联分析和编辑器。
