# Agent Note: 工作台配置使用本机目录选择

Status: Implemented

## Problem

本地路径需要由用户明确选择，界面仍要保留路径配置。

## Decision

接入已验收的原生设置和本机目录选择入口。

## Alternatives considered

现存材料未记载该项决定曾比较的其他方案。

## Consequences

原生选择器是 Windows 工作台行为，其他平台没有同等验收。
