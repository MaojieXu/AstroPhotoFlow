# Agent Note: 紧凑原生节点控件与可撤销参数恢复

Status: Implemented

## Problem

Data 节点依赖手动路径输入，标题、文件名和来源多次显示，单张导航和固定最小高度占用画布。软件结果卡常驻结果文件名、运行 ID、日志和下载链接，通道按钮外观突兀。新增批量恢复默认参数后，真实浏览器验证还发现浮点回调把 0.25 舍入为 0.3，以及撤销重建同 ID 节点后组件仍持有旧实例的问题。

## Decision

Data 复用素材库的本机文件选择接口，单文件路径注入后接续既有导入。取消、失败或目标实例变化时保留原绑定，保留手动路径展开入口和自定义标题。单张去重名称并隐藏导航，完整资料移入详情，运行后的保存到素材库与导出到本机保留。

软件结果卡使用原生通道下拉框和更多菜单，通道只改变媒体读取选择，不提交软件调用。参数区增加小型重置按钮，高级参数沿用原生开关，默认值来自实例构造器的定义。批量修改以一次原生撤销事务提交，回调通知后仍保持声明默认值，自动模式由既有合并机制提交一次。

原生浮点自动精度至少容纳默认值的小数位，用户指定精度继续优先。控件容器在属性变更后重新解析当前实例，尺寸观察器同步归属。预览内容高度使用原生 DOM 测量，序列化几何只设置基础最小高度，后续显示变化不写入内容几何。

## Alternatives considered

另做文件选择器会复制本机入口与取消逻辑。复制默认参数或硬编码 Siril 默认值会与节点版本脱节。逐参数提交撤销或执行会产生多次历史和运行。重建节点来重置参数会危及引用、连线、标题和位置。保留两个高级参数开关会重复原生能力。

## Consequences

Data 导入前和运行后共用紧凑规则，预览失败可单独重试。浏览器回归使用真实合成 RGB FITS，检查路径注入、完整数据操作入口、菜单、高级参数、通道查看的队列与文件不变、一次撤销及自动模式单次提交。完整日志和截图保存在 .artifacts/reports/node-ui。
