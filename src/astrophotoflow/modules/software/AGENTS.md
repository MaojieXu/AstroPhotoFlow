# ③ 外部软件接入与环境 开发边界

- 先读本目录 README 与[模块导航](../../../../docs/architecture/module-map.md)，再读取任务涉及的契约。
- 管理项目提供的软件包及配套节点，展示安装版本和可用状态；更新前确认影响，执行观察交⑤，统一发现由⑤协调。
- core、contracts；数据通过稳定引用和数据模块公开操作交接。
- 当前状态：概要设计已成文，尚无软件包管理、软件适配器或统一检索实现；不创建占位接口。
- 仅修改任务所属模块；跨模块使用公开入口，不直接引用其 ORM、私有函数或前端内部 Store。
- 不创建假接口、空服务类或预注册能力；新实现必须更新真实状态与验收记录。
- 验证入口：本模块尚无独立实现与测试；首次实现必须补充明确的验证入口。
