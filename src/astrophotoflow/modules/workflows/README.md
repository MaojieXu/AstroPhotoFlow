打开项目 → 原生画布读取或拖入②固定素材 → 手动或Agent编排 → 原生引擎处理 → 各已执行图像节点自动预览 → 用户选择完整结果保存 → 后续交互接续。深空原始素材、行星原始视频和叠加图后期均沿[统一场景](../../../../docs/requirements/README.md#scenario-processing)，具体科学操作由③软件提供。

<a id="authority"></a>

## 2. 职责和边界

⑤统一拥有项目到原生图的关联、当前工作流保存规则、运行记录、多次完成预览、当前人工／Agent控制，以及派生能力目录和按需检索。代码归属 `modules/workflows`，MCP协议适配仍归 `interfaces`，原生宿主协调仍归 `frontend/src/platform/astrophotoflow`。

①提供配置、认证、事务和维护机制；②保存项目资料、资产、集合和记忆，解析科学引用并保存用户选择结果；③管理软件包及实际调用观察；④保存节点定义及更新前后内容。⑤消费它们的公开能力，不读私有ORM，不将导入任务迁成图运行，也不将其状态复制成新的权威。

ComfyUI负责图转换、校验、队列、执行、进度和取消；原生文件是唯一当前图，运行快照只是当次事实。平台补必要项目关联、持久记录、自动预览和在线桥接，不增加第二套图调度、权限矩阵或通用恢复系统。版权、作者归属与发布认证不作当前建模目标；软件许可准备仍遵循③。

<a id="objects"></a>

## 3. 必要数据

只保留当前图、一次运行、多次完成预览、当前人工／Agent控制四类内容，细节见[数据设计](../../../../docs/architecture/data-models/05-workflows.md#2-只保留四类必要数据)。项目使用原生持久图编号及文件位置，实例、连线、参数和布局保持原生完整JSON；当前内容校验只用于避免覆盖新修改，不建立永久逐编辑版本。

运行保存当次编辑图／执行图、固定输入与解释、实际参数、节点和软件信息、原生任务编号、状态错误日志及必要调用事实。测试也使用同一运行记录，④只读取最近一次及链接。预览关联工作流、运行、节点和输出位置；控制只保存是否允许Agent继续与识别旧请求的标记。目录和索引是派生信息，不持久保存通用协作账本、控制交接历史或画布回执。

<a id="flows"></a>

## 5. 使用流程

新图先选择项目并原生保存/关联后才交给Agent；不增加服务端临时图或临时控制生命周期。控制状态按图共享，未被手动接管时换客户端可继续；明确接管后仍须用户交回。

### 编辑和再次打开

当前图自动保存；原生JSON是唯一当前内容。重要方案用原生“另存为”成为独立图；会话内按人和Agent的共同先后撤销。重开可读取保存图和各次运行所用图，不承诺恢复每一次没有运行过的编辑。恢复旧运行方案时明确载入其图内容，不改旧运行事实；需要保留当前方案时先另存。

浏览器本地草稿不代表已保存；断连如实显示，重连先查询既有保存和目标内容，分歧保留草稿，不自动覆盖、合并或重放。缺依赖JSON保留待修复，不自动安装、换节点或猜测执行图；普通导出只包含图，不等于导出素材、节点包和软件。

### 真实运行和预览

确认当前图及范围 → 原生运行前控件准备与graphToPrompt各一次 → 核对没有人工变化且参数／拓扑一致 → 原生保存当前画布一次，失败阻止提交 → ②固定输入／⑤记录实际采用内容后再次核对 → ⑤最终交原生队列调度并调用③ → 检查科学产物及生成轻量UI预览 → 保存运行与多次预览 → 用户选择完整结果时交②保存。转换是准备而非执行，不要求双保存或重跑随机控件。

原生运行按钮、快捷键、自动队列及MCP的托管运行统一经过⑤提交能力，再使用原生队列和调度，保存同类实际运行事实；Agent来源须核对当前控制，人工运行无需先交回Agent。该提交桥接尚未实现，不能因MCP有检查就认为原生入口已覆盖。

默认可复现并说明必要输入准备成本，已有固定托管内容不重复复制；显式仅引用说明较弱保证，失败不自动降级，不改变导入方式。新运行读取②当前纠正资料并记录；集合成员保持用户选定范围，科学输入不被预览替代。

整图使用明确终点，指定目标包含必要依赖；实际请求范围不静默缩小。普通中间节点的目标转换仍需验证。科学处理默认不跨运行自动复用，先验证原生cache-none机制；不靠写入无关run编号假装缓存失效。编辑、加载、自动保存和添加节点不执行软件。

自动预览伴随本次实际执行完成的图像节点，科学结果与UI显示分离，不将全部节点设为终点，不增加预览调度器。保存多次完成预览，批量图像关联具体输出；不保存实时进度每帧。以原生任务编号关联所属工作流；A后台完成时预览仍归A，不串B，不自动切回画布。缓存回放不是新处理。

完整工作文件供本次下游使用，不长期保留；只有用户选择的完整图片登记素材，可命名或默认命名，预览无需先登记。删除工作流清理专属预览，不删除已保存完整素材。未规定预览数量、期限或清理格式，旧预览不能证明完整文件仍在。

取消请求与实际停止分别给出依据；不可中断或状态未知不假报成功，不误停其他任务。提交断连后先查已有运行及引擎事实，不自动重提；完成但素材保存失败先核对文件及登记，补登记不创造新调用。完整重跑产生新运行；S6显式续跑仅复用已保存可用的固定科学结果，不依赖预览或内存缓存，不新增续跑管理对象。

### Agent与人工交替

首版用户在目标网页点击“交给Agent”绑定该页面当前图；Agent日常通过局部原生操作编辑，整图JSON用于导入或明确替换。编辑和新提交依托已打开、明确目标的活动画布；切走后暂停对原图的后续修改／提交，不自动跟随其他页面，已受理运行继续，返回后重新核对。无网页对工作流仍可查状态及列表，不支持新编辑／新运行；②导入、③安装等非画布操作仍按所属规则提供，不增加无画布转换器或多画布并发协作。

手动参数、节点、连线、布局和撤销即接管；查看、平移、缩放或切换页签不接管。写入及新运行受理处核对当前目标、内容和控制标记，拒绝迟到旧写；读取、重连和新上下文不恢复已撤销Agent控制，用户明确交回后才继续。离线接管未确认时如实显示；接管不取消既有任务。

手动变化后保持安静，下次用户交互由经验证客户端／Skill读取明确目标的最新内容、同步和控制状态；不要求任意外部模型必然遵守。普通任务连续操作，不逐节点弹权限框。敏感动作按所属业务的明确计划确认；不建立作者身份、角色矩阵或通用审批模型。

Skill／已有workflow及已知能力直接使用；需要发现时检索业务工具、节点定义和软件操作，候选分型、最多10项、完整定义按需读。固定本地embedding不可用时明确关键词降级及原因。各来源提供真实就绪说明，搜索不扩大授权、不自动安装、替换或重试。模型、融合和索引待原型；记忆仍归②，首版调参由外部Agent推进，Judge仅后续外部评价边界。

## 6. 对外能力和交接

| 交接 | 保证及失败含义 | 联调入口 |
|---|---|---|
| ① ↔⑤ | 实际运行／占用交维护检查，未知不作空闲；认证不替代当前图控制 | 繁忙重启拒绝，状态与连接一致 |
| ② ↔⑤ | 固定素材／组、当前资料、所选完整结果及来源关联；缺失、变化与保存失败如实说明 | 选材、移除提示、两类输入保证、保存结果及核对 |
| ③ ↔⑤ | 软件就绪、准确实现及真实调用观察；连接不等于成功，取消不等于已停 | 软件更新等待运行结束、科学文件交接及实际停止 |
| ④ ↔⑤ | 定义内容及更新前后差异；④不保存运行副本 | 更新前确认，全部参数新默认，未变端口保线、变化端口断线；最近测试查询 |
| 原生／接入层 ↔⑤ | 复用加载、保存、撤销、转换、队列和UI事件；返回受理、保存、实际显示、执行和素材保存各自结果 | 活动画布目标、迟到请求、切图后的预览归属及真实MCP |

对外操作为打开／保存／另存、读取／修改当前图、运行／查询／取消、读取预览／保存所选结果、接管／明确交回，以及定义读取／按需检索。具体HTTP、MCP设计名及字段统一维护在[接口契约](../../../../docs/api/platform-contracts.md)，不是已可调用接口，不创建空实现。
