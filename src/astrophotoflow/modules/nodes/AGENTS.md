# 节点模块约束

- 节点定义存于工作流 JSON，本模块只维护可编辑定义、更新差异与派生目录；不建节点执行器，Bundle 原生加载在 `interfaces/native/bundles/`。
- 保存不以测试通过为门槛；"最近测试"只读取实际软件调用与结果，不据此推定保存权限。
- 更新先确认影响；实例参数与端口调整由原生桥接执行，实例保留全参数时采用新版默认。
- 同方向且同名同类型的端口保持连线（含重排）；端口语义变化时断开对应连线；输入、输出各自名称唯一。
- 不扩展到任意第三方节点；在途内容与历史不因定义更新改写；名称与分类来自声明及 Bundle 双语显示资料，分类变化不改节点类型、端口或执行绑定。
- 测试位置 `tests/modules/nodes/`。
