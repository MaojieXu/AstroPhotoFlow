# ② 数据与资产管理 开发边界

- 先读本目录 README 与[模块导航](../../../../docs/architecture/module-map.md)，再读取任务涉及的契约。
- 资产与集合版本、元数据、设备快照、原件与预览生命周期。
- core、contracts；其他模块只通过明确公开入口调用。
- 当前状态：已有资产、集合、设备资料、导入、预览、校准引用和回收站实现。
- 仅修改任务所属模块；跨模块使用公开入口，不直接引用其 ORM、私有函数或前端内部 Store。
- 不创建假接口、空服务类或预注册能力；新实现必须更新真实状态与验收记录。
- 验证入口：`uv run --locked --no-sync pytest tests/modules/data -q`
