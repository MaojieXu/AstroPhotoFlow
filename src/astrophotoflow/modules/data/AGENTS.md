# 数据模块约束

- 稳定素材身份、数据集当前成员顺序、资料 revision 与省略/`null`/`0` 语义是持久不变量；新运行使用纠正后的资料，已产生的旧运行不改写。
- 来源登记、原件可读、解析与预览分层处理；预览与查看状态不是科学输入，不写入分析结果。
- 公开交接不暴露私有 ORM；跨模块只经 `public.py`；图、队列、执行历史归 ComfyUI，具体软件调用归 software，已检查结果归 data。
- `formats/` 只处理文件格式，不依赖导入流水线、ORM 或 HTTP；颜色布局读取只改内存解释，不覆盖原件。
- 测试位置 `tests/modules/data/`；样本数据在 `tests/data/`。
